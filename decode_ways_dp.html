The Problem

Decode Ways (LeetCode #91)

A message was encoded by replacing each letter with its number: A=1, B=2, ... Z=26. Given a string of digits, return how many ways to decode it.

2 2 6
Split 1: 2 | 2 | 6 = B, B, F
Split 2: 22 | 6 = V, F
Split 3: 2 | 26 = B, Z
3 ways to decode "226"
How is this different from Climbing Stairs? Staircase ALWAYS looks back 1 and 2 steps. Decode Ways has to CHECK the digits first. A "0" can't be a letter. "37" can't be a letter. You only look back when the digits are valid.

Step 1: What Are My Choices?

At each position: one or two ways to read

Standing at position 3 (digit "6" in "226"). Two doors to check:

DOOR 1: Read 1 digit
Take just "6" → F (valid letter, 1 through 9).
If this single digit is 1 through 9, it's a letter.

+= ways[position - 1]
DOOR 2: Read 2 digits
Take "26" → Z (valid letter, 10 through 26).
If these two digits form 10 through 26, it's a letter.

+= ways[position - 2] 
ways[position] = 0
IF single digit valid (1-9):   add ways[position - 1]
IF double digit valid (10-26): add ways[position - 2]
Three possible states:
Both doors open → two look-backs (like staircase)
One door open → one look-back
Both doors locked → dead end (ways = 0)

Step 2: Choices → Recursion

The code writes itself from the choices

digits = "226"

def decode_ways(position):
    if position == 0: return 1   # empty string = 1 way
    total = 0

    single_digit = int(digits[position - 1])
    if single_digit >= 1:               # Door 1: valid letter?
        total += decode_ways(position - 1)

    if position >= 2:
        double_digit = int(digits[position - 2:position])
        if 10 <= double_digit <= 26:    # Door 2: valid pair?
            total += decode_ways(position - 2)

    return total

decode_ways(3)
Door 1: single_digit >= 1
If this single digit is a valid letter (A through I), open the door and look back 1.
Door 2: 10 <= double_digit <= 26
If this pair of digits is a valid letter (J through Z), open the door and look back 2.

The Tricky Cases: When Does Each Door Open?

This is the KEY section for Decode Ways

DOOR 1: Single Digit Check
0 LOCKED. 0 is NOT a letter.
1 2 3 4 5 6 7 8 9 OPEN. A through I.
DOOR 2: Double Digit Check
00 through 09: LOCKED. Leading zero. Not a valid encoding.
10 through 26: OPEN. J through Z.
27 through 99: LOCKED. Past Z (26). No letter there.

Example: "106"

1 0 6
Position 1 (digit "1"): Door 1 OPEN (A). Door 2: only 1 digit, N/A. ways = 1
Position 2 (digit "0"): Door 1 LOCKED (0 is not a letter!). Door 2 OPEN (10 = J). ways = 1
Position 3 (digit "6"): Door 1 OPEN (F). Door 2 LOCKED (06 has a leading zero). ways = 1

Answer: 1 way. Only: J, F. The "0" forces "10" to be read as a pair.

Example: "30" (the dead end)

3 0
Position 1 (digit "3"): Door 1 OPEN (C). ways = 1
Position 2 (digit "0"): Door 1 LOCKED (0 invalid). Door 2 LOCKED (30 > 26). ways = 0

Answer: 0 ways. DEAD END. "30" cannot be decoded at all. Both doors locked.

"0" is the trap. It locks Door 1 always. Door 2 only opens if the pair is 10 or 20. Any other digit before 0 (like 30, 40, 50...) means the string can't be decoded.

Step 4: Memoize

Same code, just cache the answers

def decode_ways(position, memo={}):
    if position in memo: return memo[position]
    if position == 0: return 1
    total = 0

    single_digit = int(digits[position - 1])
    if single_digit >= 1:
        total += decode_ways(position - 1, memo)

    if position >= 2:
        double_digit = int(digits[position - 2:position])
        if 10 <= double_digit <= 26:
            total += decode_ways(position - 2, memo)

    memo[position] = total
    return total

The cache for "226": position 0 → 1, position 1 → 1, position 2 → 2, position 3 → 3.

The Tabulation Code

Every line maps to something we just did

def decode_ways(digits):
    length = len(digits)
    ways = [0] * (length + 1)
    ways[0] = 1

    for position in range(1, length + 1):
        single_digit = int(digits[position - 1])
        if single_digit >= 1:
            ways[position] += ways[position - 1]

        if position >= 2:
            double_digit = int(digits[position - 2:position])
            if 10 <= double_digit <= 26:
                ways[position] += ways[position - 2]

    return ways[length]

Staircase vs Decode Ways

Same structure, conditional look-backs

Climbing Stairs
ways[step] = ways[step-1] + ways[step-2]
Look-backs: ALWAYS both
No conditions. Just add.
Decode Ways
ways[pos] = (if valid) + (if valid)
Look-backs: CHECK first
Conditional. Digit must be valid.
Same 1D array. Same left-to-right fill. The difference: conditional look-backs.
Staircase: always look back 1 and 2.
Decode Ways: check each digit before looking back.
"0" is the trap. It locks Door 1 and might lock Door 2.
