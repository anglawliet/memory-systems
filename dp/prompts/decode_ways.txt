DECODE WAYS: Full Walkthrough
===============================
The student already knows Climbing Stairs and House Robber.
Decode Ways is the CONDITIONAL look-back problem. Teach fully:
question, choices, recursion, tree, array, fill, code.

The core idea: staircase ALWAYS looks back 1 and 2. Decode Ways
checks IF the digits are valid BEFORE each look-back.

Example: digits = "226"
  "2|2|6" = B,B,F    "22|6" = V,F    "2|26" = B,Z
  Answer: 3 ways

Descriptive names:
  ways[position]     not  dp[i]
  single_digit       not  s[i]
  double_digit       not  s[i-1:i+1]
  digits             not  s

Images produced:
  Prompt 1 -> decode_ways_1.png  (The Question + The Choices)
  Prompt 2 -> decode_ways_2.png  (Recursion + Tree + The Tricky Cases)
  Prompt 3 -> decode_ways_3.png  (The Array + Filling Every Cell + Code)

Code in a dark navy code block:
  digits = "226"

  def decode_ways(position):
      if position == 0: return 1
      total = 0

      single_digit = int(digits[position - 1])
      if single_digit >= 1:
          total += decode_ways(position - 1)

      if position >= 2:
          double_digit = int(digits[position - 2:position])
          if 10 <= double_digit <= 26:
              total += decode_ways(position - 2)

      return total

  decode_ways(3)

SECTION 3 (badge: "8"), "THE CODE":
Header: "THE SOLUTION"

Code in a dark navy code block:
  def decode_ways(digits):
      length = len(digits)
      ways = [0] * (length + 1)
      ways[0] = 1

      for position in range(1, length + 1):
          single_digit = int(digits[position - 1])
          if single_digit >= 1:
              ways[position] += ways[position - 1]

          if position >= 2:
              double_digit = int(digits[position - 2:position])
              if 10 <= double_digit <= 26:
                  ways[position] += ways[position - 2]

      return ways[length]

Annotations:
  ways[0] = 1                   ->  "Empty string = 1 way (do nothing)"
  single_digit >= 1             ->  green door: "Door 1: valid letter?"
  10 <= double_digit <= 26      ->  orange door: "Door 2: valid pair?"
  += ways[position - 1]         ->  "Open Door 1: add from one back"
  += ways[position - 2]         ->  "Open Door 2: add from two back"
  return ways[length]           ->  "Last cell = total decodings"

Gold highlight box at the bottom:
  "STAIRCASE vs DECODE WAYS:
   Staircase: ALWAYS look back 1 and 2.
   Decode:    CHECK each digit before looking back.

   Same 1D array. Same left-to-right fill.
   The difference: conditional look-backs.
   '0' is the trap. It locks Door 1 and might lock Door 2."
