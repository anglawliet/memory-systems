Two branches:

Branch LEFT (RED, "skip"): count_ways(1,0)

Two branches:
  - skip: count_ways(2,0). source[2]='b' != target[0]='a'. Skip only.
    count_ways(3,0). i==len(source), j<len(target). Return 0. RED.
  - use: count_ways(2,1). source[2]='b' == target[1]='b'. MATCH!
    skip: count_ways(3,1). i==len(source). Return 0.
    use: count_ways(3,2). j==len(target). Return 1! GREEN star!
    Total: 0+1 = 1
  Total: 0+1 = 1

Branch RIGHT (GREEN, "use"): count_ways(1,1)
source[1]='a' != target[1]='b'. No match. Skip only.
count_ways(2,1). source[2]='b' == target[1]='b'. MATCH!
  skip: count_ways(3,1). i==len(source). Return 0.
  use: count_ways(3,2). j==len(target). Return 1! GREEN star!
  Total: 0+1 = 1

Root total: skip(1) + use(1) = 2

Kit at the bottom pointing up with speech bubble: "Two green stars, two valid subsequences. Skip + Use = 2."

================================================================================

---BEGIN STYLE BIBLE---

Create a tall portrait infographic (1024x1792). Five sections stacked (slightly smaller cards).

Big header: "DON'T MAKE THESE MISTAKES"

Kit at the top, arms crossed, looking stern.

MISTAKE 1 (RED card):
Header: "Using MAX instead of +"
Show: "return max(skip, use)" RED X
vs "return skip + use" GREEN check
Below: "We COUNT ways, not find the best. Addition, not maximum."

MISTAKE 2 (RED card):
Header: "Advancing target on mismatch"
Show: "if mismatch: count_ways(i+1, j+1)" RED X
vs "if mismatch: count_ways(i+1, j)" GREEN check
Below: "Target is fixed! Never skip target characters."

MISTAKE 3 (RED card):
Header: "Swapping base case values"
Show: "target done: return 0, source done: return 1" RED X
vs "target done: return 1, source done: return 0" GREEN check
Below: "Target done = spelled it! (1). Source empty but target left = impossible (0)."

MISTAKE 4 (RED card):
Header: "Forgetting skip branch on match"
Show: "if match: return count_ways(i+1, j+1)" RED X (only counts use)
vs "if match: return skip + count_ways(i+1, j+1)" GREEN check
Below: "Skipping a match is valid! It might lead to more total ways."

MISTAKE 5 (RED card):
Header: "Wrong 1D iteration direction"
Show: "for j in range(0, cols):" RED X
vs "for j in range(cols-1, -1, -1):" GREEN check
Below: "Space-optimized version needs RIGHT-TO-LEFT to avoid overwriting."
