  def min_edits(i, j, word1, word2):

  if j == len(word2):
      return len(word1) - i

YELLOW/GOLD background:
  if word1[i] == word2[j]:
      return min_edits(i + 1, j + 1, word1, word2)

AMBER background:
  replace = 1 + min_edits(i + 1, j + 1, word1, word2)

RED background:
  delete = 1 + min_edits(i + 1, j, word1, word2)

BLUE background:
  insert = 1 + min_edits(i, j + 1, word1, word2)

PURPLE background:
  return min(replace, delete, insert)

Color legend at the bottom:
- GREEN = "Promise: minimum edits for remaining substrings"
- BLUE = "Base cases: empty string = length of the other"
- YELLOW = "Match check: free pass, no operation needed"
- AMBER = "Replace: fix this position, both advance"
- RED = "Delete: remove from word1, only i advances"
- BLUE (lighter) = "Insert: add from word2, only j advances"
- PURPLE = "Combine: minimum of all three operations"

word1="ab", word2="adb"

Level 1: word1[0]='a' == word2[0]='a' (GREEN match, free!)
Goes to: min_edits(1,1)

Level 2: word1[1]='b' != word2[1]='d' (RED mismatch!)
Three branches:
- AMBER: replace -> min_edits(2,2)
- RED: delete -> min_edits(2,1)
- BLUE: insert -> min_edits(1,2)

Level 3 from replace min_edits(2,2):
i==len(word1), return len(word2)-j = 3-2 = 1. Total: 1+1 = 2

Level 3 from delete min_edits(2,1):
i==len(word1), return len(word2)-j = 3-1 = 2. Total: 1+2 = 3

Level 3 from insert min_edits(1,2):
word1[1]='b' == word2[2]='b' (GREEN match!)
Goes to min_edits(2,3): both done, return 0. Total: 1+0 = 1

Return values bubbling up: min(2, 3, 1) = 1

Kit at the bottom pointing at the insert path with speech bubble: "INSERT wins! Just 1 operation."

Create a tall portrait infographic (1024x1792). Four sections stacked.

Big header: "DON'T MAKE THESE MISTAKES"

Kit at the top, arms crossed, looking stern.

MISTAKE 1 (RED card):
Header: "Forgetting +1 on each operation"
Show: "replace = min_edits(i+1, j+1)" RED X
vs "replace = 1 + min_edits(i+1, j+1)" GREEN check
Below: "Each operation COSTS 1. Don't forget it!"

MISTAKE 2 (RED card):
Header: "Using MAX instead of MIN"
Show: "return max(replace, delete, insert)" RED X
vs "return min(replace, delete, insert)" GREEN check
Below: "We want MINIMUM operations, not maximum."

MISTAKE 3 (RED card):
Header: "Base case returns 0 instead of remaining length"
Show: "if i == len(word1): return 0" RED X
vs "if i == len(word1): return len(word2) - j" GREEN check
Below: "Empty word1 still needs insertions for remaining word2!"

MISTAKE 4 (RED card):
Header: "Swapping insert and delete pointers"
Show: "insert: (i+1, j)" and "delete: (i, j+1)" RED X
Below: "INSERT adds to word1 to match word2[j], so j advances."
Below: "DELETE removes from word1, so i advances."
