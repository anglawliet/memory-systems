Current state: i=0, j=0. Looking at word1[0]='h' and word2[0]='r'. They DON'T match.

SECTION 1: "MATCH (when chars are equal)" (GREEN card, about 20%):

Show a case where word1[i] == word2[j] (e.g., 'o' == 'o'):
  Action: "Characters match. No operation needed."
  Cost: +0
  i changes: i -> i+1 "word1[i] consumed (it matched)"
  j changes: j -> j+1 "word2[j] produced (the match covers it)"
  Call: min_edits(i+1, j+1)

SECTION 2: "REPLACE" (AMBER card, about 25%):

Show word1[0]='h', word2[0]='r'. Overwrite 'h' with 'r'.
  Action: "Overwrite word1[i] to become word2[j]"
  Cost: +1 (one replace operation)
  i changes: i -> i+1 "word1[i] consumed (we replaced it, it's now correct)"
  j changes: j -> j+1 "word2[j] produced (the replacement covers it)"
  Call: 1 + min_edits(i+1, j+1)
  "Both advance: replace handles BOTH positions at once."

SECTION 3: "DELETE" (RED card, about 25%):

Show word1[0]='h'. Remove it entirely.
  Action: "Remove word1[i] from word1"
  Cost: +1 (one delete operation)
  i changes: i -> i+1 "word1[i] consumed (we deleted it)"
  j STAYS: j unchanged "Nothing was produced for word2. word2[j] still waiting."
  Call: 1 + min_edits(i+1, j)
  "Only i moves. Deleting doesn't help word2."

SECTION 4: "INSERT" (BLUE card, about 25%):

Show: insert 'r' (= word2[0]) before word1[0].
  Action: "Insert word2[j] into word1 at position i"
  Cost: +1 (one insert operation)
  i STAYS: i unchanged "word1[i] NOT consumed. Still there, still needs handling."
  j changes: j -> j+1 "word2[j] produced (we inserted it)"
  Call: 1 + min_edits(i, j+1)
  "Only j moves. Inserting doesn't consume word1."

Kit at bottom: "Every state change = something consumed or produced.
If nothing was consumed, that pointer doesn't move."

Create a tall portrait infographic (1024x1792). Two sections.

SECTION 1, "THE OVERLAP" (purple header, about 50%):

Big header: "EDIT DISTANCE: MEMOIZE"
Subtitle: 'word1 = "horse", word2 = "ros"'

Show a recursion tree for min_edits(i, j).
At each node: (i, j). Start at (0,0).

(0,0): 'h' != 'r'. THREE branches:
  Replace: (1,1) [amber arrow]
  Delete:  (1,0) [red arrow]
  Insert:  (0,1) [blue arrow]

Expand (1,1): 'o' == 'o'. Match! One branch:
  (2,2) [green arrow]

Expand (1,0): 'o' != 'r'. Three branches:
  Replace: (2,1)
  Delete:  (2,0)
  Insert:  (1,1)  <-- OVERLAP! Already seen!

Expand (0,1): 'h' != 'o'. Three branches:
  Replace: (1,2)
  Delete:  (1,1)  <-- OVERLAP! Already seen!
  Insert:  (0,2)

CIRCLE (1,1) with GOLD border: "Same state from 3 different paths!"
"Replace reaches (1,1). Delete reaches (1,1). Insert reaches (1,1).
Different operations, same remaining subproblem."

"3 branches per mismatch. Overlap grows FAST."
"Without cache: O(3^(m+n)). With cache: O(m * n)."

Kit: "Every mismatch creates 3 branches. Overlaps pile up quickly.
Cache key: (i, j). At most 5 x 3 = 15 unique states."

SECTION 2, "THE CODE" (gray header, about 50%):

Show the memoized code:

  def min_edits(word1, word2, i, j, cache):
      if i == len(word1):
          return len(word2) - j
      if j == len(word2):
          return len(word1) - i
      if (i, j) in cache:
          return cache[(i, j)]
      if word1[i] == word2[j]:
          result = min_edits(word1, word2, i + 1, j + 1, cache)
      else:
          replace = 1 + min_edits(word1, word2, i + 1, j + 1, cache)
          delete = 1 + min_edits(word1, word2, i + 1, j, cache)
          insert = 1 + min_edits(word1, word2, i, j + 1, cache)
          result = min(replace, delete, insert)
      cache[(i, j)] = result
      return result

Highlight each operation with its color:
  GREEN: match line
  AMBER: replace line
  RED: delete line
  BLUE: insert line

Kit: "Same 3 lines as always: check cache, compute, store.
The operations are different, the memoization pattern is identical."

SECTION 2, "THE CODE" (gray header, about 45%):

  def min_edits(word1, word2):
      rows = len(word1)
      cols = len(word2)
      table = [[0] * (cols + 1) for _ in range(rows + 1)]
      for i in range(rows + 1):
          table[i][0] = i
      for j in range(cols + 1):
          table[0][j] = j
      for i in range(1, rows + 1):
          for j in range(1, cols + 1):
              if word1[i - 1] == word2[j - 1]:
                  table[i][j] = table[i - 1][j - 1]
              else:
                  table[i][j] = 1 + min(
                      table[i - 1][j - 1],
                      table[i - 1][j],
                      table[i][j - 1]
                  )
      return table[rows][cols]

Color-code the three directions in the else block:
  AMBER: table[i-1][j-1] = replace (diagonal)
  RED: table[i-1][j] = delete (up)
  BLUE: table[i][j-1] = insert (left)

Kit: "Edge base cases: first column = cost of deleting all word1 chars.
First row = cost of inserting all word2 chars."

Gold box: "Why directions map to operations:
Diagonal (i-1,j-1): replace consumes word1[i] AND produces word2[j].
Up (i-1,j): delete consumes word1[i], word2[j] still waiting.
Left (i,j-1): insert produces word2[j], word1[i] still waiting."
