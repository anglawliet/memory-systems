  7. TABULATE: changing variables → table dimensions, base cases → first row/col
  8. Fill table bottom-up using the same formula from recursion

  def knapsack(wt, val, W, n):
      # BASE CASE: no items left OR no capacity
      if n == 0 or W == 0:
          return 0

      if wt[n-1] <= W:

Big highlighted callout (gold border):

  def knapsack(wt, val, W, n, memo):

      memo[(n, W)] = result         # STORE the result
      return result

Code block — TABULATION:
  def knapsack(wt, val, W, n):
      dp = [[0] * (W+1) for _ in range(n+1)]
      for i in range(1, n+1):
          for j in range(1, W+1):
              if wt[i-1] <= j:
                  dp[i][j] = max(val[i-1] + dp[i-1][j-wt[i-1]],
                                 dp[i-1][j])
              else:
                  dp[i][j] = dp[i-1][j]
      return dp[n][W]


PROMPT 4 OF 4 — All Three Versions + The Knapsack Family (Pages 8-10)

PAGE 8 — "THE PIPELINE" (LARGE circled 8 top-right):
Header: "RECURSION → MEMOIZATION → TABULATION"
Subtitle: "Same logic, three forms."

Show 3 code blocks side by side (or stacked), with DIFF HIGHLIGHTS showing what changes:

VERSION 1 — RECURSION (label: "correct but SLOW, O(2^n)"):
  def knapsack(wt, val, W, n):
      if n == 0 or W == 0:
          return 0
      if wt[n-1] <= W:
          grab = val[n-1] + knapsack(wt, val, W-wt[n-1], n-1)
          skip = knapsack(wt, val, W, n-1)
          return max(grab, skip)
      else:
          return knapsack(wt, val, W, n-1)

VERSION 2 — MEMOIZATION (label: "add 3 lines, O(n*W)"):
  Highlight the 3 NEW lines in GREEN:
  def knapsack(wt, val, W, n, memo={}):
      if (n, W) in memo: return memo[(n, W)]   # CHECK cache
      if n == 0 or W == 0:
          return 0
      if wt[n-1] <= W:
          grab = val[n-1] + knapsack(wt, val, W-wt[n-1], n-1, memo)
          skip = knapsack(wt, val, W, n-1, memo)
          result = max(grab, skip)
      else:
          result = knapsack(wt, val, W, n-1, memo)
      memo[(n, W)] = result                     # STORE result
      return result

VERSION 3 — TABULATION (label: "bottom-up, O(n*W), no recursion"):
  def knapsack(wt, val, W, n):
      dp = [[0]*(W+1) for _ in range(n+1)]
      for i in range(1, n+1):
          for j in range(1, W+1):
              if wt[i-1] <= j:
                  dp[i][j] = max(val[i-1] + dp[i-1][j-wt[i-1]],
                                 dp[i-1][j])
              else:
                  dp[i][j] = dp[i-1][j]
      return dp[n][W]

Arrow from recursion → memoization: "Add a cache. 3 lines."
Arrow from memoization → tabulation: "Replace recursion with loops. Same formula."
