       SKIP = row above at [same column]
       Pick the MAX"

  def best_haul(treasures, bag_limit):
      table = [[0] * (bag_limit + 1) for _ in range(len(treasures) + 1)]
      for row in range(1, len(treasures) + 1):
          name, weight, value = treasures[row - 1]
          without_this = table[row - 1]
          for cap in range(1, bag_limit + 1):
              if weight <= cap:
                  grab = value + without_this[cap - weight]
                  skip = without_this[cap]
                  table[row][cap] = max(grab, skip)
              else:
                  table[row][cap] = without_this[cap]
      return table[len(treasures)][bag_limit]
