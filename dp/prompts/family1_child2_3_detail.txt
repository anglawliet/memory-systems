  {11} = 11. YES!
  "If Bag A holds exactly half, Bag B automatically holds the other half!"

  "EQUAL PARTITION = SUBSET SUM with target = total / 2"
  "We already know how to solve Subset Sum!"

SECTION 3, "THE CODE" (gray header, about 25%):

  def can_partition(nums):
      total = sum(nums)

      if total % 2 != 0:
          return False

      target = total // 2
      return can_reach(nums, target, 0)

Annotate:
  total % 2 != 0 <- "Odd? Impossible. Stop immediately."
  total // 2 <- "Half the total is our target."
  can_reach(nums, target, 0) <- "Subset Sum! We solved this."

Kit: "No new choices to learn. Just recognize: equal split = find half."

Header: "WATCH THE COUNTING"
Subtitle: "Numbers = [2, 3, 5], target = 5. How many subsets sum to 5?"

Draw the recursion tree. Each node shows (number being decided, current target).
Green = TAKE, Red = LEAVE.

                    [Looking at 2]
                     target = 5
                    /            \
              TAKE 2           LEAVE 2
                 |                |
           [Looking at 3]    [Looking at 3]
            target = 3        target = 5
            /        \        /        \
       TAKE 3    LEAVE 3  TAKE 3   LEAVE 3
          |          |       |         |
      [Look at 5] [Look 5] [Look 5] [Look 5]
      target=0   target=3  target=2  target=5
        |          |         |          |
     ZERO!     TAKE 5?    TAKE 5?    TAKE 5
     1 WAY     3<5? no,   2<5? no,   target=0
               but 5>3    but 5>2    ZERO!
               must leave must leave 1 WAY
               target=3   target=2
               no nums    no nums
               0 WAYS     0 WAYS

Wait, let me recalculate. [2, 3, 5], target = 5:

At [2], target=5:
  TAKE 2: target=3, look at [3]
    TAKE 3: target=0. HIT ZERO! 1 way. (subset {2,3})
    LEAVE 3: target=3, look at [5]
      TAKE 5: 5 > 3, can't take. Must leave.
      LEAVE 5: target=3, no nums. 0 ways.
      Result: 0 + 0 = 0
    Result: 1 + 0 = 1
  LEAVE 2: target=5, look at [3]
    TAKE 3: target=2, look at [5]
      TAKE 5: 5 > 2, can't take. Must leave.
      LEAVE 5: target=2, no nums. 0 ways.
      Result: 0 + 0 = 0
    LEAVE 3: target=5, look at [5]
      TAKE 5: target=0. HIT ZERO! 1 way. (subset {5})
      LEAVE 5: target=5, no nums. 0 ways.
      Result: 1 + 0 = 1
    Result: 0 + 1 = 1
  TOTAL: 1 + 1 = 2

Show this tree clearly. At each leaf:
  target = 0: green card, "1 WAY" (this combination works)
  no nums left: red card, "0 WAYS" (this combination failed)

At each internal node, show the ADDITION bubbling up:
  "1 + 0 = 1 ways"
  "0 + 1 = 1 ways"
  "1 + 1 = 2 ways total"

Label the two successful paths:
  Path 1: TAKE 2, TAKE 3 -> {2, 3} = 5
  Path 2: LEAVE 2, LEAVE 3, TAKE 5 -> {5} = 5

SECTION 2, "OR vs PLUS" (gold header, about 35%):

Header: "THE CRUCIAL DIFFERENCE"

Show side by side:

SUBSET SUM (or):                  COUNT SUBSETS (+):
"Does ANY path hit zero?"         "How MANY paths hit zero?"
True or False = True              1 + 0 = 1
True or True = True               1 + 1 = 2
False or False = False            0 + 0 = 0
"One success is enough"           "Every success counts"

Kit: "Same tree. Same choices. Just a different question at the bottom.
Subset Sum asks 'any?' Count Subsets asks 'how many?'"

Gold box:
  "Subset Sum: base case returns True/False. Combine with OR.
   Count Subsets: base case returns 1/0. Combine with +.
   That's the ONLY difference."

SECTION 2, "THE CODE" (gray header, about 40%):

Header: "FROM REASONING TO CODE"

  def count_subsets(nums, target, index):

      if target == 0:                <- "Found a valid group! Count: 1"
          return 1

      if index == len(nums):         <- "No items left. Count: 0"
          return 0

      if nums[index] > target:       <- "Too big. Must leave."
          return count_subsets(
              nums, target,
              index + 1)

      take = count_subsets(          <- "TAKE: target shrinks"
          nums,
          target - nums[index],
          index + 1)

      leave = count_subsets(         <- "LEAVE: target stays"
          nums,
          target,
          index + 1)

      return take + leave            <- "ADD the ways. Not OR."

Annotate with arrows. Highlight "return take + leave" in gold.

Header: "SEE THE PATTERN GROWING"

  Choices:              Choices:
  take or leave         take or leave           SAME!
