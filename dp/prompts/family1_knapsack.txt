FAMILY 1: 0/1 KNAPSACK, THE PARENT PROBLEM
==============================================
8 prompts total: 1 character reference + 7 tutorial images (1024x1792 each).
Teaching style: Aditya Verma's pipeline. Choices first, recursion from choices,
notice overlapping subproblems (WHY it's DP), then table from recursion.

Theme: Casino Vault Heist (Vegas connection to graph Scene 1).
Kit breaks into a Vegas casino vault. 5 treasures on pedestals, each with a
WEIGHT tag and VALUE tag. Kit has a duffel bag with a weight limit of 7 kg.
At each treasure: GRAB IT or SKIP IT. Goal: maximize total value.

Characters:
  Kit = the vault raider (makes choices at each treasure)
  Sack = the duffel bag (knapsack, tracks remaining capacity)
  Branch = the holographic choice projector (shows TAKE vs SKIP paths)

The 5 Vault Treasures:
  1. Gold Bar Stack: weight 4, value $10K (heavy gold bars)
  2. Ruby Collection: weight 3, value $7K  (case of rubies)
  3. Diamond Display: weight 5, value $12K (large diamond centerpiece)
  4. Emerald Ring Box: weight 1, value $3K  (small ring box)
  5. Platinum Watches: weight 2, value $5K  (watch display case)

  bag_limit = 7

  Optimal: Gold (4,$10K) + Emerald (1,$3K) + Platinum (2,$5K) = weight 7, value $18K

Teaching pipeline (Aditya Verma style):
  1. See the problem -> What CHOICES do you have at each item?
  2. Draw the CHOICE DIAGRAM (branching tree)
  3. Write RECURSION directly from the choice diagram
  4. Draw the RECURSIVE TREE -> notice the SAME subproblems appear multiple times
  5. THAT'S WHY IT'S DP! Same subproblem, same answer, why compute twice?
  6. MEMOIZE: just add a cache (store results, check before computing)
  7. TABULATE: changing variables -> table dimensions, base cases -> first row/col
  8. Fill table bottom-up using the same formula from recursion

Header: "RECURSION -> MEMOIZATION -> TABULATION"
Subtitle: "Same logic, three forms."

Show 3 code blocks side by side (or stacked), with DIFF HIGHLIGHTS showing what changes:

VERSION 1, RECURSION (label: "correct but SLOW, O(2^count)"):
  def max_value(treasures, bag_limit, count):
      if count == 0 or bag_limit == 0:
          return 0
      name, weight, value = treasures[count - 1]
      if weight <= bag_limit:
          grab = value + max_value(treasures, bag_limit - weight, count - 1)
          skip = max_value(treasures, bag_limit, count - 1)
          return max(grab, skip)
      else:
          return max_value(treasures, bag_limit, count - 1)

VERSION 2, MEMOIZATION (label: "add 3 lines, O(count * bag_limit)"):
  Highlight the 3 NEW lines in GREEN:
  def max_value(treasures, bag_limit, count, memo={}):
      if (count, bag_limit) in memo: return memo[(count, bag_limit)]   # CHECK
      if count == 0 or bag_limit == 0:
          return 0
      name, weight, value = treasures[count - 1]
      if weight <= bag_limit:
          grab = value + max_value(treasures, bag_limit - weight, count - 1, memo)
          skip = max_value(treasures, bag_limit, count - 1, memo)
          result = max(grab, skip)
      else:
          result = max_value(treasures, bag_limit, count - 1, memo)
      memo[(count, bag_limit)] = result                                # STORE
      return result

VERSION 3, TABULATION (label: "bottom-up, O(count * bag_limit), no recursion"):
  def max_value(treasures, bag_limit):
      table = [[0] * (bag_limit + 1) for _ in range(len(treasures) + 1)]
      for row in range(1, len(treasures) + 1):
          name, weight, value = treasures[row - 1]
          without_this = table[row - 1]
          for cap in range(1, bag_limit + 1):
              if weight <= cap:
                  table[row][cap] = max(value + without_this[cap - weight],
                                        without_this[cap])
              else:
                  table[row][cap] = without_this[cap]
      return table[len(treasures)][bag_limit]

Arrow from memoization -> tabulation: "Replace recursion with loops. Same formula."
