SECTION 3, "THE COMBINE STEP" (amber header, about 30%):

Header: "min() instead of max()"

  "Parent unbounded: max(take_again, move_on)  -> maximize VALUE"
  "Coin Change:      min(use_again, move_on)   -> minimize COINS"

  use_again = 1 + min_coins(coins, amount - coin, index)
  move_on = min_coins(coins, amount, index + 1)
  return min(use_again, move_on)

  "The '1 +' counts each coin I use."
  "min() picks the path with fewer coins."

Base cases:
  amount == 0: return 0. "No more money needed. Zero coins."
  no coins left, amount > 0: return infinity. "Can't make it. Impossible."

SECTION 2, "THE CODE" (gray header, about 35%):

Header: "THE OPTIMIZED 1D CODE"

  def coin_change(coins, amount):
      dp = [float('inf')] * (amount + 1)
      dp[0] = 0

      for coin in coins:
          for a in range(coin, amount + 1):
              dp[a] = min(dp[a], dp[a - coin] + 1)

      if dp[amount] == float('inf'):
          return -1
      return dp[amount]

Annotate:
  dp[0] = 0 <- "0 coins to make amount 0"
  float('inf') <- "Impossible until proven otherwise"
  range(coin, amount + 1) <- "LEFT to RIGHT! Allows reuse."
  dp[a - coin] + 1 <- "Use this coin (+1) on top of best for remainder"
  min() <- "Keep the fewer coins"

Gold box: "LEFT TO RIGHT loop = unbounded (reuse allowed).
Compare to 0/1 Subset Sum which loops RIGHT TO LEFT (no reuse)."

  USE [2]: "How many ways to make 3 with [2] and remaining coins?"

Compare three siblings:
  PARENT:        max(take_again, move_on)  "Best value"

SECTION 3, "WHY OUTER LOOP = COINS" (amber header, about 30%):

Header: "Avoiding duplicate counting"

"If we loop amount first, then coins, we'd count
[1,2] and [2,1] as DIFFERENT. But they're the same combination!"

  WRONG (inner = coins): at amount 3, tries [1]+[2] AND [2]+[1]. Counts twice!

  Once we move past a coin, we never go back to it.
  This ensures each combination is counted exactly once."

Gold box: "This is the COMBINATIONS vs PERMUTATIONS distinction.

Outer=amounts would give PERMUTATIONS (order matters)."

  def count_ways(coins, amount):
      dp = [0] * (amount + 1)
      dp[0] = 1

      for coin in coins:
          for a in range(coin, amount + 1):
              dp[a] += dp[a - coin]

      return dp[amount]

Annotate:
  dp[0] = 1 <- "One way to make 0: use no coins."
  for coin in coins <- "OUTER loop = coins. Process each coin fully."
  range(coin, amount + 1) <- "LEFT to RIGHT. Allows reuse."
  dp[a] += dp[a - coin] <- "Add ways: using this coin + remaining."

Show the dp array being filled for coins=[1,2], amount=4:

  After processing coin=1:
  dp = [1, 1, 1, 1, 1]
  "Only one way with just 1s: [1,1,...,1]"

  dp = [1, 1, 2, 2, 3]
  "Amount 4: {1,1,1,1}, {2,1,1}, {2,2}. Three ways."

SECTION 2, "THE UNBOUNDED FAMILY TREE" (teal header, about 50%):

Tree diagram:
  UNBOUNDED KNAPSACK (parent)
  "Use again (STAY) or move on (ADVANCE)"

Create a tall portrait infographic (1024x1792). Two sections.

SECTION 1, "THE CODE" (gray header, about 55%):

Header: "FROM REASONING TO CODE"

  def word_break(s, word_dict):
      words = set(word_dict)
      dp = [False] * (len(s) + 1)
      dp[0] = True

      for end in range(1, len(s) + 1):
          for start in range(end):
              if dp[start] and s[start:end] in words:
                  dp[end] = True
                  break

      return dp[len(s)]

Annotate:
  dp[0] = True <- "Empty prefix is always valid."
  for end <- "Check each position: can I reach here?"
  for start <- "Try every possible last word ending at 'end'."
  dp[start] <- "Was the prefix up to 'start' valid?"
  s[start:end] in words <- "Is this chunk a real word?"
  dp[end] = True <- "Yes! I can reach position 'end'."
  break <- "One valid way is enough. Stop checking."
  dp[len(s)] <- "Can I reach the very end?"

Show the dp array for "leetcode" with ["leet", "code"]:
  Position: 0   1   2   3   4   5   6   7   8
  dp:       T   F   F   F   T   F   F   F   T
                              ^                ^
                          "leet" ends       "code" ends
                          here (valid!)     here (valid!)

  "dp[4] = True because dp[0] is True AND s[0:4] = 'leet' is a word."
  "dp[8] = True because dp[4] is True AND s[4:8] = 'code' is a word."

SECTION 2, "HOW THIS CONNECTS TO UNBOUNDED KNAPSACK" (teal header, about 45%):

Header: "THE ANALOGY"

Show the connection:
