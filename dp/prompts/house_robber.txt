HOUSE ROBBER: Full Walkthrough
================================
The student has done the staircase page but needs House Robber
explained from scratch. No "twist" comparisons. Teach it on its own:
question, choices, recursion, tree, overlap, array, fill, code.

Example: money = [2, 7, 9, 3, 1]

Descriptive names:
  money[house]        not  nums[i]
  best[house]         not  dp[i]
  best_haul(house)    not  rob(i) (recursive function)
  rob_this            not  dp[i-2] + nums[i]
  skip_this           not  dp[i-1]

Images produced:
  Prompt 1 -> house_robber_1.png  (The Problem + The Choices)
  Prompt 2 -> house_robber_2.png  (Recursion + Tree + Overlap)
  Prompt 3 -> house_robber_3.png  (The 1D Array: what it means, base cases)
  Prompt 4 -> house_robber_4.png  (Filling every cell, step by step)

  )

  best_haul(-1) = 0           "No house here. $0."
  best_haul(0)  = money[0]    "One house. Rob it."

Full code in a dark navy code block:
  money = [2, 7, 9, 3, 1]

  def best_haul(house):
      if house < 0: return 0
      if house == 0: return money[0]
      rob_this  = money[house] + best_haul(house - 2)
      skip_this = best_haul(house - 1)
      return max(rob_this, skip_this)

  best_haul(4)   # start from the last house

Annotations to the right of the code block (small colored labels):
  rob_this  -> green label: "grab cash, skip neighbor"
  skip_this -> orange label: "walk past, keep previous best"

      if house in memo: return memo[house]
      if house < 0: return 0
      if house == 0: return money[0]

      return memo[house]

THE CODE (dark navy code block):
  def max_robbery(money):
      house_count = len(money)
      if house_count == 0: return 0
      if house_count == 1: return money[0]

      best = [0] * house_count
      best[0] = money[0]
      best[1] = max(money[0], money[1])

      for house in range(2, house_count):
          skip_this = best[house - 1]
          rob_this  = best[house - 2] + money[house]
          best[house] = max(skip_this, rob_this)

      return best[house_count - 1]

Annotations (small colored labels to the right of each line):
  best[0] = money[0]                ->  "One house? Rob it."
  best[1] = max(money[0], money[1]) ->  "Two houses? Rob richer one."
  skip_this = best[house - 1]       ->  orange: "Walk past"
  rob_this = best[house - 2] + ...  ->  green: "Grab cash, skip neighbor"
  max(skip_this, rob_this)          ->  "Pick the better deal"
  return best[house_count - 1]      ->  "Last cell = maximum haul"

Bottom gold highlight box:
  "THE PATTERN (same every time):
   1. Read the constraint -> find the choices
   2. Choices -> formula: max(skip, rob)
   3. Base cases -> first cells
   4. Fill left to right
   5. Last cell = the answer"
