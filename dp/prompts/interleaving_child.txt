PROMPT 5: Common Mistakes -> interleaving_mistakes.png
================================================================================

---BEGIN STYLE BIBLE---
[Paste the full style bible from above here]
---END STYLE BIBLE---

Create a tall portrait infographic (1024x1792). Four sections stacked.

Big header: "DON'T MAKE THESE MISTAKES"

Kit at the top, arms crossed, looking stern.

MISTAKE 1 (RED card):
Header: "Forgetting the length check"
Show: jumping straight to recursion without checking len(s1)+len(s2)==len(s3)
RED X. Below: "If lengths don't add up, answer is always False!"
Fix: "Add early return: if len(s1)+len(s2) != len(s3): return False"

MISTAKE 2 (RED card):
Header: "Storing k as a separate variable"
Show: "can_interleave(i, j, k)" with 3 params. RED X
vs "k = i + j" computed inside. GREEN check
Below: "k is ALWAYS i+j. Extra param wastes memo space (3D instead of 2D)."

MISTAKE 3 (RED card):
Header: "Treating no-match as 'skip' instead of False"
Show: "if neither matches: skip to next" RED X
vs "if neither matches: return False" GREEN check
Below: "Every s3 character MUST come from somewhere. No match = dead end."

MISTAKE 4 (RED card):
Header: "Using AND instead of OR"
Show: "return try_s1 AND try_s2" RED X
vs "return try_s1 OR try_s2" GREEN check
Below: "We need ANY valid interleaving, not ALL paths to work."
