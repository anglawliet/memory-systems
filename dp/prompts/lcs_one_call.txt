LCS ONE RECURSIVE CALL (landscape, condition splits left / right)
==============================================================
Landscape 1536x1024. Explains exactly ONE invocation of
lcs(text1_index, text2_index).

ORIENTATION: landscape, deliberately. This diagram is a FORK, and a
fork needs two columns side by side so both outcomes can be compared
at a glance. Portrait was tried and rejected: it squeezed the columns
to ~380px, forced every call to wrap, and shortened the grey bars so
much that the single purple highlight stopped standing out.

CODE FLOW: read top to bottom in the order the function runs.
   STEP 1  base case guard        (first line of the function)
   STEP 2  compare the letters    (the if)
   STEP 3  left column,  match  -> return 1 + one call
   STEP 4  right column, differ -> return max of two calls
A code panel top right carries the same 1-2-3-4 badges.

DE-CLUTTER: a string is a plain flat GREY BAR. Only the ONE current
element is highlighted. Used parts are faded and crossed out.

NAMING: text1 with text1_index, text2 with text2_index.
Calls are EXPRESSIONS with the numeric form under them.
Steps 3 and 4 are an IF / ELSE, so they NEVER merge.
==============================================================
