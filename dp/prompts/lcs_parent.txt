STYLE BIBLE
================================================================================

---BEGIN STYLE BIBLE---

IMAGE FORMAT: Tall portrait infographic (1024x1792).

TEXT RULES:
- ALL text must be HUGE. Section titles 60pt+, body text 32pt+, code 26pt+.
- Every element must be readable on a phone held vertically WITHOUT zooming.
- Maximum 15 words per explanation. Let the visuals carry the meaning.
- White space is OK. Don't cram. Better to be clear than dense.
- All text rendered in a clean sans-serif font (like Nunito or Poppins).
  NO chalk-style text, NO handwritten fonts, NO serif fonts.

CHARACTER (Kit, appears in EVERY image with this EXACT look):
- Young person, mid-20s, master vault raider.
- Hair: SHORT MESSY DARK BROWN hair. Never long, never neat, never styled.
- Face: sharp dark eyes, confident smirk, light stubble. Round head.
- Outfit (EVERY image, NO exceptions):
  * SLEEK BLACK TACTICAL SUIT (one-piece, fitted, matte black).
  * DARK BLUE UTILITY BELT around the waist.
  * FINGERLESS BLACK GLOVES on both hands.
  * Compact NIGHT-VISION GOGGLES pushed up on forehead (always visible).
- Build: lean and athletic. Calm, calculated confidence.
- Proportions: Pixar/Disney-style 3D render. Head slightly oversized
  (about 1/4 of body height). Big eyes. Smooth plastic-like skin.

ART STYLE:
- Soft 3D cartoon render (Pixar energy). NOT flat, NOT photorealistic, NOT anime.
- Smooth rounded shapes, soft shadows, slight subsurface scattering on skin.
- Clean vector-like line quality on diagrams and text boxes.

COLOR PALETTE:
- Background: dark purple-blue (#1E1035). Grid/matrix atmosphere.
- Section cards: cream/warm-white (#FFF8F0) with rounded corners, subtle shadow.
- Headers: bright purple (#8B5CF6).
- Code blocks: light gray (#F3F4F6) rounded boxes, large monospace font.
- Gold accents: (#F59E0B) for callouts and highlights.
- Green: (#22C55E) for match/free paths. Red: (#EF4444) for mismatch/cost.
- Amber: (#F59E0B) for replace. Blue: (#3B82F6) for insert.
- Purple accent lighting throughout.

---END STYLE BIBLE---

def lcs_length(text1, text2, i, j):
    if i == len(text1) or j == len(text2):
        return 0
    if text1[i] == text2[j]:
        return 1 + lcs_length(text1, text2, i+1, j+1)
    skip_first = lcs_length(text1, text2, i+1, j)
    skip_second = lcs_length(text1, text2, i, j+1)
    return max(skip_first, skip_second)

================================================================================

---BEGIN STYLE BIBLE---
[Paste the full style bible from above here]

Create a tall portrait infographic (1024x1792). Four sections.

Big header at top: "COMMON MISTAKES"

Kit at the top looking concerned, pointing at errors.

SECTION 1 (RED card, about 22%):
Title: "+1 ON THE SKIP BRANCH"
Show code: "return 1 + lcs(i+1, j)" with big X mark.
"Skipping matches nothing. +0, not +1."
Fix: "Skip adds 0. Only match adds 1."
Detection: 'lcs("a","b") returns 1 instead of 0'

SECTION 2 (RED card, about 22%):
Title: "ADD INSTEAD OF MAX"
Show code: "lcs(i+1,j) + lcs(i,j+1)" with big X mark.
"Addition counts all paths."
"LCS wants the SINGLE longest."
Fix: "max(skip_first, skip_second)"

SECTION 3 (RED card, about 22%):
Title: "ONLY ONE POINTER ON MATCH"
Show code: "1 + lcs(i+1, j)" with big X mark.
Show: j stays, text2[j] gets matched AGAIN later.
"Double-counting! Match uses BOTH characters."
Fix: "1 + lcs(i+1, j+1)"

SECTION 4 (RED card, about 22%):
Title: "BASE CASE RETURNS 1"
Show code: "if i == len(text1): return 1" with big X mark.
"Running out isn't success. It's the end."
"No match happened here."
Fix: "return 0"
