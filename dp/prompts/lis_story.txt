LIS STORY-FIRST IMAGES v3 (Longest Increasing Subsequence, LeetCode #300)
==============================================================
16 panels, grouped into three layers.
  LAYER 1 THE STORY        panels 1 to 6   (understand it, no code)
  LAYER 2 THE ALGORITHM    panels 7 to 12  (write it)
  LAYER 3 THE CODE         panels 13 to 16 (ship it)
Running example: numbers = [5, 6, 1, 2, 3]
==============================================================

================================================================================
STYLE BIBLE
================================================================================

---BEGIN STYLE BIBLE---

IMAGE FORMAT: Tall portrait infographic, mobile first.

TEXT RULES:
- ALL text HUGE. Titles 60pt+, body 32pt+, code 26pt+.
- Readable on a phone held vertically WITHOUT zooming.
- About 60 words of body text per panel, not counting the banners.
  Prefer fragments over sentences. Prefer a diagram over a paragraph.
- NO multi row tables inside a panel. Tables belong in the article.
- Clean sans serif font (Nunito or Poppins). NO chalk, NO handwriting, NO serif.
- Plain words only. Write for a bright ten year old. Never use the words
  "delegate", "predecessor", "exhaustive", "transition", "dependency",
  "optimal" or "iterate" anywhere in a panel.

=== LAYER BADGE (every panel) ===
Top left corner, a small rounded pill badge, one of exactly these:
     "LAYER 1  THE STORY"        pill colour SKY CYAN (#38BDF8)
     "LAYER 2  THE ALGORITHM"    pill colour GOLD (#F59E0B)
     "LAYER 3  THE CODE"         pill colour VIOLET (#A78BFA)
Small. It must not compete with the title.

=== NAMING (use these EXACT names, never abbreviate) ===
the list is always:        numbers
the function is always:    longest_chain_ending_at(current_index)
the loop variable:         previous_index
the running best:          longest_so_far
the table:                 longest_chain_ending_at[current_index]
   (same name as the function, round brackets become square brackets)
the store:                 solved_lengths
NEVER write i, j, n, m, dp, f, go, solve, rec or arr in any panel.

=== EVERY NUMBER MUST BE LABELLED ===
A bare number is forbidden. Every number carries a small word saying what it is:
   INDEX    a spot in the list
   VALUE    the number sitting at that spot
   LENGTH   an answer handed back, how many numbers are in a chain
   BEST     the best found so far inside one call
Any panel showing more than two numbers includes a small NUMBER LEGEND box:
   INDEX  = BLUE   (#38BDF8)
   VALUE  = WHITE / DARK GREY
   LENGTH = GREEN  (#22C55E)
   BEST   = PURPLE (#A78BFA)
Wrong or not allowed things are RED (#EF4444).
Colour is never the only signal. The word label is always there too.

=== INDEX AND VALUE GO ON SEPARATE ROWS ===
Whenever the list appears, draw two labelled rows lined up in columns:
   INDEX:    0    1    2    3    4        <- small blue text
   VALUE:    5    6    1    2    3        <- large boxes
Never merge them.

=== SUMS CARRY THEIR MEANING ===
Never draw a bare sum. Every term gets a caption underneath:
        1                +          2               =        3
   "my own number,             "LENGTH handed           "LENGTH of the
    that is one"                back from below"         whole chain"

=== STORY BANNERS ===
Every panel starts with a thin top banner "WE ALREADY KNOW: ..."
and ends with a thin bottom banner "SO NEXT: ...". One short line each.

CHARACTER (Kit, in EVERY panel, this EXACT look):
- Young person, mid 20s, master vault raider.
- Hair: SHORT MESSY DARK BROWN. Never long, never neat.
- Face: sharp dark eyes, confident smirk, light stubble. Round head.
- Outfit, every time, no exceptions:
  * SLEEK BLACK TACTICAL SUIT, one piece, fitted, matte black.
  * DARK BLUE UTILITY BELT.
  * FINGERLESS BLACK GLOVES on both hands.
  * Compact NIGHT VISION GOGGLES pushed up on the forehead, always visible.
- Lean and athletic. Calm, calculated confidence.
- Pixar/Disney style 3D render. Head slightly oversized, about 1/4 of body
  height. Big eyes. Smooth plastic like skin.
- Kit appears ONCE per panel, small, at an edge. Kit never covers the diagram.

ART STYLE:
- Soft 3D cartoon render, Pixar energy. NOT flat, NOT photoreal, NOT anime.
- Smooth rounded shapes, soft shadows.
- Clean vector like lines on diagrams and text boxes.

COLOR PALETTE:
- Background: deep navy teal (#0B1F2A), faint grid.
- Cards: cream / warm white (#FFF8F0), rounded, soft shadow.
- Headers: bright sky cyan (#38BDF8).
- Code blocks: light grey (#F3F4F6) rounded boxes, large monospace.
- Gold (#F59E0B) for callouts.
- Number colours exactly as in the NUMBER LEGEND above.

RUNNING EXAMPLE (identical in every panel showing data):
   INDEX:  0   1   2   3   4
   VALUE:  5   6   1   2   3

---END STYLE BIBLE---

ZONE 2 (bottom): a light grey code block, big monospace, TEAL highlight
on exactly three lines. Mark the three highlighted lines with a small teal dot.

      solved_lengths = {}                              <- teal

      def longest_chain_ending_at(current_index):
          if current_index in solved_lengths:          <- teal
              return solved_lengths[current_index]     <- teal
          longest_so_far = 1
          for previous_index in range(current_index):
              if numbers[previous_index] < numbers[current_index]:
                  longest_so_far = max(longest_so_far,
                                       1 + longest_chain_ending_at(previous_index))
          solved_lengths[current_index] = longest_so_far
          return longest_so_far

Three short teal cards on the right, each level with its own teal line:
      "an empty box"
      "already done? hand it back."
      "fill it before returning"
