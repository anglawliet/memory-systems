LIS STORY-FIRST IMAGES v2 (Longest Increasing Subsequence, LeetCode #300)
==============================================================
15 panels. One connected story. Running example: numbers = [5, 6, 1, 2, 3]
Built to the STORY-FIRST tutor prompt including RULE 10.5
(descriptive names, every number typed, index separated from value,
arithmetic annotated with units, number legend on every data panel).
==============================================================

================================================================================
STYLE BIBLE
================================================================================

---BEGIN STYLE BIBLE---

IMAGE FORMAT: Tall portrait infographic, mobile first.

TEXT RULES:
- ALL text must be HUGE. Section titles 60pt+, body text 32pt+, code 26pt+.
- Readable on a phone held vertically WITHOUT zooming.
- WORD BUDGET: about 60 words of body text per panel, not counting the top
  and bottom banners. Prefer fragments over sentences. Prefer a diagram
  over a paragraph. White space is good. Do not cram.
- NO multi-row tables inside a panel. Tables belong in the article, not the image.
- Clean sans-serif font (Nunito or Poppins). NO chalk, NO handwriting, NO serif.

=== NAMING (use these EXACT names, never abbreviate them) ===
The array is always called:            numbers
The function is always called:         longest_chain_ending_at(current_index)
The loop variable is always called:    previous_index
The running best is always called:     longest_so_far
The table is always called:            longest_chain_ending_at[current_index]
   (same name as the function: round brackets become square brackets)
The cache is always called:            solved_lengths

NEVER write i, j, n, m, dp, f, go, solve, rec, or arr anywhere in any panel.

=== EVERY NUMBER MUST BE TYPED ===
A bare number is forbidden. Every number carries a small text label saying
what KIND of number it is. Use these role words:
   INDEX      a position in the array
   VALUE      the number stored at that position
   LENGTH     a returned answer, how many elements are in a chain
   BEST       the best answer found so far inside one call

NUMBER LEGEND: any panel showing more than two numbers must include a small
legend box with these four rows, using these exact colours:
   INDEX  = BLUE   (#38BDF8)
   VALUE  = WHITE/DARK GREY, plain
   LENGTH = GREEN  (#22C55E)
   BEST   = PURPLE (#A78BFA)
Invalid or rejected things are RED (#EF4444).
Colour is never the only signal. The text label is always present too.

=== INDEX AND VALUE ARE DRAWN ON SEPARATE ROWS ===
Whenever the array appears, draw it as TWO labelled rows, aligned in columns:

   INDEX:    0    1    2    3    4        <- small blue text
   VALUE:    5    6    1    2    3        <- large boxes

Never merge them. Never write a position and a value as one number.

=== ARITHMETIC CARRIES UNITS ===
Never draw bare arithmetic. Every term gets a caption under it. Like this:

        1                +          2               =        3
   "the current                "LENGTH returned          "LENGTH of the
    element itself"             by the smaller call"      whole chain"

=== CONNECTED STORY BANNERS ===
Every panel begins with a thin banner at the very top:
   "WE ALREADY KNOW: ..."
and ends with a thin banner at the very bottom:
   "SO NEXT: ..."
These are short, one line each.

CHARACTER (Kit, appears in EVERY panel with this EXACT look):
- Young person, mid-20s, master vault raider.
- Hair: SHORT MESSY DARK BROWN hair. Never long, never neat, never styled.
- Face: sharp dark eyes, confident smirk, light stubble. Round head.
- Outfit (EVERY image, NO exceptions):
  * SLEEK BLACK TACTICAL SUIT (one-piece, fitted, matte black).
  * DARK BLUE UTILITY BELT around the waist.
  * FINGERLESS BLACK GLOVES on both hands.
  * Compact NIGHT-VISION GOGGLES pushed up on forehead (always visible).
- Build: lean and athletic. Calm, calculated confidence.
- Proportions: Pixar/Disney-style 3D render. Head slightly oversized
  (about 1/4 of body height). Big eyes. Smooth plastic-like skin.
- Kit appears ONCE per panel, small, at an edge. Kit never covers the diagram.

ART STYLE:
- Soft 3D cartoon render (Pixar energy). NOT flat, NOT photorealistic, NOT anime.
- Smooth rounded shapes, soft shadows, slight subsurface scattering on skin.
- Clean vector-like line quality on diagrams and text boxes.

COLOR PALETTE:
- Background: deep navy teal (#0B1F2A). Grid/matrix atmosphere.
- Section cards: cream/warm-white (#FFF8F0), rounded corners, soft shadow.
- Headers: bright sky cyan (#38BDF8).
- Code blocks: light gray (#F3F4F6) rounded boxes, large monospace font.
- Gold accents (#F59E0B) for callouts.
- Number-role colours exactly as listed in the NUMBER LEGEND section above.

RUNNING EXAMPLE (identical in every panel that shows data):
   INDEX:  0   1   2   3   4
   VALUE:  5   6   1   2   3

---END STYLE BIBLE---
