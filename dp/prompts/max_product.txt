Running example: numbers = [-2, 3, -4]  answer 24

STYLE BIBLE
================================================================================

---BEGIN STYLE BIBLE---

IMAGE FORMAT: Tall portrait infographic, mobile first.

TEXT RULES:
- ALL text HUGE. Titles 60pt+, body 32pt+, code 26pt+.
- Readable on a phone held vertically WITHOUT zooming.
- About 60 words of body text per panel, not counting banners.
  Fragments over sentences. Diagram over paragraph.
- NO multi row tables inside a panel unless the panel IS a grid.
- Clean sans serif (Nunito or Poppins). NO chalk, NO handwriting, NO serif.
- Plain words. Write for a bright ten year old. Never use the words
  "delegate", "predecessor", "exhaustive", "transition", "optimal", "iterate".

=== NAMING (exact, never abbreviate) ===
the list is always:      numbers
the running max:         best_ending_here
the running min:         worst_ending_here
the final answer:        biggest
the current number:      value
NEVER write i, j, n, dp, f, go, solve, rec, arr.

=== EVERY NUMBER LABELLED ===
   INDEX    a spot in the list
   VALUE    the number sitting there
   BEST     biggest product of a run ending here
   WORST    smallest product of a run ending here
Panels with more than two numbers include a small NUMBER LEGEND box:
   INDEX = BLUE (#38BDF8), VALUE = WHITE, BEST = GREEN (#22C55E),
   WORST = ORANGE (#FB923C). Wrong things RED (#EF4444).
Colour is never the only signal. Word labels always present.

=== INDEX AND VALUE ON SEPARATE ROWS ===
   INDEX:   0    1    2
   VALUE:  -2    3   -4
Never merged.

=== BANNERS ===
Top thin banner "WE ALREADY KNOW: ...", bottom "SO NEXT: ...".
EXCEPT the recall panel, which has NO banners and stands alone.

CHARACTER (Kit, ONCE per panel, small, at an edge, never covering the diagram):
- Mid 20s, SHORT MESSY DARK BROWN hair, sharp dark eyes, confident smirk, stubble.
- SLEEK BLACK TACTICAL SUIT one piece matte black, DARK BLUE UTILITY BELT,
  FINGERLESS BLACK GLOVES, NIGHT VISION GOGGLES pushed up on forehead.
- Lean athletic. Pixar/Disney 3D render, head slightly oversized, big eyes.

ART STYLE: soft 3D cartoon, Pixar energy. NOT flat, NOT photoreal, NOT anime.

COLOR PALETTE:
- Background deep navy teal (#0B1F2A), faint grid.
- Cards cream / warm white (#FFF8F0), rounded, soft shadow.
- Headers bright sky cyan (#38BDF8). Code blocks light grey (#F3F4F6).
- Gold (#F59E0B) for callouts.

RUNNING EXAMPLE (every data panel):
   INDEX:   0    1    2
   VALUE:  -2    3   -4

---END STYLE BIBLE---
