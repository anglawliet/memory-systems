    is_pal(2,3) -> text[2]='b'==text[3]='a'? NO -> False
    is_pal(0,2) -> text[0]='a'==text[2]='b'? NO -> False
    is_pal(1,3) -> text[1]='a'==text[3]='a'? YES -> is_pal(2,2) -> True!
    is_pal(0,3) -> text[0]='a'==text[3]='a'? YES -> is_pal(1,2) -> False

CIRCLE the overlapping subproblems with GOLD borders:
  is_pal(2,2) called from is_pal(1,3) AND directly!
  is_pal(1,2) called from is_pal(0,3) AND directly!

"Same (left, right) pair from different starting points!"

Kit looking at circled nodes: "Overlap! Same subproblem, different callers."

Header: "THE OVERLAP PROVES IT'S DP"

is (left, right). Color the cells:
  GREEN = palindrome (True)
  RED = not palindrome (False)
  GOLD border = computed more than once (overlapping!)

The grid for "aaba":
         0    1    2    3
    0   [T]  [T]  [F]  [F]
    1        [T]  [F]  [T]
    2             [T]  [F]
    3                  [T]

Mark cells (2,2) and (1,2) with gold borders: "These were checked multiple times!"

"Without cache: some pairs checked more than once."
"With cache: each (left, right) checked exactly once. O(n^2) pairs total."

Subtitle: 'text = "abba". Which substrings are palindromes?'

Show a recursion tree for is_palindrome("abba", left, right).

and checking individual substrings also reach the same (1,2) state.

Circle the duplicate: (1,2) appears from multiple paths.
"Same substring range. Same answer. Cache it!"

Kit holding notebook: "I check each (left, right) pair ONCE."

Show the savings:
  "Cache key: (left, right). At most n^2 entries."

SECTION 2, "THE CODE" (gray header, about 55%):

Header: "ADD 3 LINES"

Show the memoized code with highlights:

  def is_palindrome(text, left, right, cache):
      if left >= right:
          return True

      if (left, right) in cache:
          return cache[(left, right)]

      if text[left] != text[right]:
          result = False
      else:
          result = is_palindrome(text, left + 1, right - 1, cache)

      cache[(left, right)] = result
      return result

Highlight the 3 new things (gold boxes):
  1. "cache parameter"
  2. "Check before computing"
  3. "Store after computing"

Kit: "Outer letters match? Check the inner substring.
Cache key = (left, right). Two pointers closing inward."

Gold box: "The pattern: shrink from both ends.
If outer matches, the answer depends on the inside."

Create a tall portrait infographic (1024x1792). Two sections.

SECTION 1, "THE TABLE" (violet header, about 50%):

Big header: "PALINDROME: TABLE"
Subtitle: 'text = "abba". Fill a 2D grid: is_pal[left][right].'

Show a 4x4 grid with rows = left (0-3), cols = right (0-3).
Only the upper triangle matters (left <= right).

Step-by-step fill order:
  1. DIAGONAL (length 1): all True. Every single character is a palindrome.
     is_pal[0][0] = True, is_pal[1][1] = True, etc. (GREEN cells)

  2. SUPER-DIAGONAL (length 2): check adjacent pairs.
     "ab" is_pal[0][1] = False (RED), "bb" is_pal[1][2] = True (GREEN),
     "ba" is_pal[2][3] = False (RED).

  3. LENGTH 3: is_pal[left][right] = text[left]==text[right] AND is_pal[left+1][right-1]
     "abb" -> 'a'!='b', False. "bba" -> 'b'!='a', False.

  4. LENGTH 4: "abba" -> 'a'=='a' AND is_pal[1][2]=True -> TRUE! (GREEN, GOLD border)

Draw arrows from is_pal[0][3] pointing diagonally inward to is_pal[1][2].
"Outer letters match + inner is palindrome = whole thing is palindrome!"

Kit looking at the filled grid: "Fill by length. Short substrings first."

SECTION 2, "THE CODE" (gray header, about 50%):

Header: "COUNT ALL PALINDROMIC SUBSTRINGS"

  def count_palindromes(text):
      n = len(text)
      is_pal = [[False] * n for _ in range(n)]
      count = 0
      for i in range(n):
          is_pal[i][i] = True
          count += 1
      for i in range(n - 1):
          if text[i] == text[i + 1]:
              is_pal[i][i + 1] = True
              count += 1
      for length in range(3, n + 1):
          for left in range(n - length + 1):
              right = left + length - 1
              if text[left] == text[right] and is_pal[left + 1][right - 1]:
                  is_pal[left][right] = True
                  count += 1
      return count

Highlight key lines:
  "Length 1: every char is a palindrome"
  "Length 2: check pairs"
  "Length 3+: check ends + look inside"

Kit: "Fill order: length 1, 2, 3, ... n.
Always have the inner answer before you need it."

Gold box: "Time: O(n^2). Space: O(n^2).
The table IS the answer, count the True cells."
