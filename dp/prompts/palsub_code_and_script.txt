PALINDROMIC SUBSTRINGS, CODE AND THE SPOKEN IDEA (practice card)
==============================================================
Landscape 1536x1024. Two panels.
LEFT  : the real code, colourful, syntax highlighted.
RIGHT : FOUR short spoken lines, very large. Nothing else.

Purpose: the user says the right hand column OUT LOUD to practise
and memorise it. Short, rhythmic, about the CHOICE and the WHY.
No paragraphs, no line by line narration, no example letters.
Describe the purpose, not the mechanics.
==============================================================

================================================================================

Create a landscape hand-drawn educational infographic, 1536x1024.

STYLE: a bright, fun classroom poster for a 10 year old, in friendly hand-drawn
marker lettering.
- Page background: soft warm cream with a faint pale dotted grid, plus a few
  small confetti dots and doodle stars in the empty areas.
- Each panel has a SOLID SATURATED colored header bar with its title in bold
  WHITE lettering, a soft pastel tint filling the body, a thick rounded outline
  and a soft drop shadow.
- One or two BIG cute cartoon doodles with smiling faces and rosy cheeks in the
  margins, never overlapping text.

TITLE across the top, very large, first word purple, rest black:
   "PALINDROMIC SUBSTRINGS  -  THE CODE,  AND THE ONE IDEA"

The page is split into TWO TALL PANELS side by side, each about half the width,
both running the full height under the title.

=== LEFT PANEL: THE CODE ===

Dark slate header bar, white text: "THE CODE".
Body is a very pale grey code card with a thin rounded border, in a neat
monospace-looking hand, with soft colour coding: keywords in purple, the
function name in blue, numbers in orange, the parameter names in dark teal,
the string values in dark red. Small line numbers down the left edge in faint
grey. No badges on the code.

   "def is_palindrome( left_index , right_index ):"
   ""
   "    if left_index >= right_index:"
   "        return True"
   ""
   "    left_letter  = text[ left_index ]"
   "    right_letter = text[ right_index ]"
   ""
   "    if left_letter != right_letter:"
   "        return False"
   ""
   "    return is_palindrome( left_index + 1 , right_index - 1 )"
   ""
   ""
   "count = 0"
   "for left in range(n):"
   "    for right in range(left, n):"
   "        if is_palindrome( left , right ):"
   "            count += 1"

Draw a thin horizontal divider line between the function and the counting loop,
with a tiny grey label on it reading "the outer count".

=== RIGHT PANEL: THE SPOKEN IDEA ===

Solid GREEN header bar, white text: "SAY THIS OUT LOUD".
Pale green body.

THE MOST IMPORTANT RULE FOR THIS PANEL: only the FOUR lines below appear here.
Write nothing else. No headings, no sub-labels, no extra sentences, no example
letters. The lettering must be VERY LARGE, much bigger than the code on the
left, with generous empty space between the lines, because these lines are meant
to be read aloud from across a room.

The FOUR lines are stacked down the panel, each with a small round coloured dot
in front of it, each on its own two or three lines of big handwriting:

   purple dot:
      "I compare the letters at the two ends of the stretch I am checking."

   green dot:
      "If they match, I move both ends inward and ask the same question about
      what is left."

   red dot:
      "If they don't match, I stop right away, because nothing inside can fix a
      bad pair at the ends."

   gold dot:
      "I return true only when the ends meet, which means every pair along the
      way matched."

Colour the key words inside those lines so the shape of the idea pops:
"the two ends" in dark teal, "match" in bright green, "move both ends inward" in
bright green, "don't match" in bright red, "I stop right away" in bright red,
"true" in purple.

At the very bottom of the right panel, one small grey chip, in noticeably
smaller lettering so it clearly sits apart from the four spoken lines:
   "an outer loop asks this for every pair of ends, then counts the true ones"

COMPOSITION: dense colourful code on the left, and a short spoken script on the
right in big airy lettering with lots of white space. The right panel should
look almost empty compared to the left. Every word spelled correctly.
