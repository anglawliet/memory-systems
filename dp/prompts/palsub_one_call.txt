PALINDROMIC SUBSTRINGS, ONE RECURSIVE CALL (landscape)
==============================================================
Landscape 1536x1024. Explains exactly ONE invocation of
is_palindrome(left_index, right_index).

SHAPE: IF / ELSE. Only one branch ever runs, so the two columns
NEVER merge, each ends in its own return.
   letters match  -> ONE call, is_palindrome(left+1, right-1)
   letters differ -> return False with NO call at all
Note the asymmetry worth teaching: the differ branch is a DEAD STOP.
It does not recurse. That is different from LCS, where both branches
recursed.

TWO POINTERS: this problem has two live positions on one bar, so the
one-highlight rule is relaxed. Left square PURPLE, right square TEAL,
each with its own label, and the span between them tinted as the part
still in question. They move INWARD toward each other.

DE-CLUTTER: the string is a plain flat GREY BAR. Only the two pointer
squares are coloured. No row of index numbers.
Calls are EXPRESSIONS with the numeric form under them.
Read text[left_index] and text[right_index] ONCE into left_letter and
right_letter, then use those names everywhere.
==============================================================
