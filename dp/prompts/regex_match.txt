Running example: text = "ab"   pattern = "a*b"   answer TRUE

STYLE BIBLE
================================================================================

---BEGIN STYLE BIBLE---

IMAGE FORMAT: Tall portrait infographic, mobile first.

TEXT RULES:
- ALL text HUGE. Titles 60pt+, body 32pt+, code 26pt+.
- Readable on a phone held vertically WITHOUT zooming.
- About 60 words of body text per panel, not counting banners.
  Fragments over sentences. Diagram over paragraph.
- Clean sans serif (Nunito or Poppins). NO chalk, NO handwriting, NO serif.
- Plain words. Write for a bright ten year old. Never use the words
  "delegate", "predecessor", "exhaustive", "transition", "optimal", "iterate".

=== NAMING (exact, never abbreviate) ===
the string being matched:  text
the pattern:               pattern
the two spots:             text_index  and  pattern_index
the question:              matches_from(text_index, pattern_index)
NEVER write i, j, n, m, dp, f, go, solve, rec, s, p.

=== EVERY VALUE LABELLED ===
   TEXT INDEX     a spot in the text
   PATTERN INDEX  a spot in the pattern
   TRUE / FALSE   the answer handed back
Panels with a grid include a small LEGEND box:
   TEXT INDEX = BLUE (#3B82F6), PATTERN INDEX = PURPLE (#8B5CF6),
   TRUE = GREEN (#22C55E), FALSE = RED (#EF4444).
Colour is never the only signal. Word labels always present.

=== THE TEXT AND THE PATTERN GO ON SEPARATE LABELLED ROWS ===
   TEXT:      a   b
   PATTERN:   a   *   b
Never merged. Always label which is which.

=== BANNERS ===
Top thin banner "WE ALREADY KNOW: ...", bottom "SO NEXT: ...".
EXCEPT the recall panel, which has NO banners and stands alone.

CHARACTER (Kit, ONCE per panel, small, at an edge, never covering the diagram):
- Mid 20s, SHORT MESSY DARK BROWN hair, sharp dark eyes, confident smirk, stubble.
- SLEEK BLACK TACTICAL SUIT one piece matte black, DARK BLUE UTILITY BELT,
  FINGERLESS BLACK GLOVES, NIGHT VISION GOGGLES pushed up on forehead.
- Lean athletic. Pixar/Disney 3D render, head slightly oversized, big eyes.

ART STYLE: soft 3D cartoon, Pixar energy. NOT flat, NOT photoreal, NOT anime.

COLOR PALETTE:
- Background warm dark brown black (#1A1916), faint grid.
- Cards cream / warm white (#FFF8F0), rounded, soft shadow.
- Headers warm gold (#D4A843). Accents amber (#F59E0B), purple (#8B5CF6),
  indigo (#6366F1). Code blocks light grey (#F3F4F6).

RUNNING EXAMPLE (every data panel):
   TEXT:      a   b          (text_index 0, 1)
   PATTERN:   a   *   b      (pattern_index 0, 1, 2)

---END STYLE BIBLE---

ZONE 1 (cream card): "THE TWO SPECIAL CHARACTERS"
Two wide rows, big:
   "."   ->  "any ONE character"       example:  a.c  matches  abc
   "*"   ->  "zero or more of the ONE character before it"
             example:  a*  matches  ""  and  "a"  and  "aaaa"
Red warning strip: "the star belongs to the letter BEFORE it. read them as a pair."

ZONE 2 (cream card, biggest zone): "THE MOVE"
Title line: "matches_from(text_index, pattern_index)  =  does the rest of the
text match the rest of the pattern?"

Two branch boxes side by side, clearly separated:

LEFT box, PURPLE border, header "PATTERN HAS A STAR NEXT":
   pair shown as  a *
   two arrows out of it:
     arrow 1 GREEN: "USE IT ZERO TIMES"  ->  "skip the pair. pattern_index + 2"
     arrow 2 BLUE:  "USE IT ONCE MORE"   ->  "only if the letter matches.
                                              text_index + 1, pattern stays"
   under both: a big "OR" in gold, and the line "either one being TRUE is enough"

RIGHT box, INDIGO border, header "NO STAR":
   "the letter must match, then step BOTH forward"
   "text_index + 1  and  pattern_index + 1"

ZONE 3 (gold card): "READING THE ANSWER"
One line: "the answer is matches_from(0, 0)"
Under it: "TRUE when we run out of text and pattern at the same time"
Small green box: 'text "" and pattern "" -> TRUE'
Small red box:   'text "" and pattern "b" -> FALSE'

ZONE 4 (small dark strip): "THE TRAP"
White text: 'an empty text can still match. "" against "a*" is TRUE.'

Kit small in a corner, arms folded.

Tall portrait. Badge: LAYER 2 THE ALGORITHM (amber pill).

Big header: "THE ONE MOVE THAT IS THE ALGORITHM"

This panel must be complete on its own.

ZONE 1 (cream card): the setup, two labelled rows with pointers.
   TEXT:      a   b        with a BLUE pointer under the a, labelled "text_index 0"
   PATTERN:   a   *   b    with a PURPLE pointer under the first a,
                           labelled "pattern_index 0"
One line: "we ask: does the rest of the text match the rest of the pattern?"

ZONE 2: "FIRST, LOOK AT WHAT COMES AFTER THE PATTERN LETTER"
A decision splitting into two big branch cards.

LEFT CARD, PURPLE border, header "A STAR COMES NEXT   (a *)":
   Two sub branches drawn as two arrows going down:

   BRANCH 1, GREEN, "USE IT ZERO TIMES":
       "throw the pair away"
       shows PATTERN with a and * greyed out and crossed
       "pattern_index jumps by 2. text_index does not move."

   BRANCH 2, BLUE, "USE IT ONE MORE TIME":
       "only if the text letter matches the pattern letter"
       shows the a in the text ticked off
       "text_index moves by 1. pattern_index stays put."

   Under both, a huge gold "OR" and the line:
       "if EITHER is TRUE, the answer is TRUE"

RIGHT CARD, INDIGO border, header "NO STAR":
   "the letters must match right now"
   shows a green tick between a text letter and a pattern letter
   "then both move forward by 1"
   Small red note: "if they do not match, FALSE straight away"

ZONE 3 (gold card): "OUR EXAMPLE"
   text "ab" against pattern "a*b"
   Branch 1 (zero times): "b" left to match against "b"... but text is still "ab" -> FALSE
   Branch 2 (one more):   the a matches, so now "b" against "a*b" -> TRUE
   Big gold result: "TRUE, because branch 2 worked"
One line: "we only needed ONE branch to work."

Include the LEGEND box, small.
Kit small at an edge, one finger raised.

Bottom banner: "SO NEXT: store the answers in a grid so we never redo one."
