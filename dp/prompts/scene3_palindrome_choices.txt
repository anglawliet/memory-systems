    |               |

  [X] the string itself - never changes
  [X] any count - we just return True/False

"State = (left, right). Two pointers closing inward."

Gold box: "How to find the state: ask 'What information changes?'

Create a tall portrait infographic (1024x1792). Two sections.

SECTION 1, "THE RECURSION TREE" (violet header, about 55%):

Big header: "PALINDROME: THE RECURSIVE TREE"
Subtitle: 'Count palindromic substrings in "aaba".'

Show the FULL recursion tree. The outer function calls is_palindrome
for EVERY (left, right) pair where left <= right.

Draw a tree showing all calls:
  count_palindromes("aaba")
    is_pal(0,0) -> True (single char)
    is_pal(1,1) -> True (single char)
    is_pal(2,2) -> True (single char)
    is_pal(3,3) -> True (single char)
    is_pal(0,1) -> text[0]='a'==text[1]='a'? YES -> is_pal(1,0) -> base: True!
    is_pal(1,2) -> text[1]='a'==text[2]='b'? NO -> False
    is_pal(2,3) -> text[2]='b'==text[3]='a'? NO -> False
    is_pal(0,2) -> text[0]='a'==text[2]='b'? NO -> False
    is_pal(1,3) -> text[1]='a'==text[3]='a'? YES -> is_pal(2,2) -> True!
    is_pal(0,3) -> text[0]='a'==text[3]='a'? YES -> is_pal(1,2) -> False

CIRCLE the overlapping subproblems with GOLD borders:
  is_pal(2,2) called from is_pal(1,3) AND directly!
  is_pal(1,2) called from is_pal(0,3) AND directly!

"Same (left, right) pair from different starting points!"

Kit looking at circled nodes: "Overlap! Same subproblem, different callers."

SECTION 2, "WHY MEMOIZE" (gold header, about 45%):

Header: "THE OVERLAP PROVES IT'S DP"

Show a grid visualization: a 4x4 upper-triangle grid where each cell
is (left, right). Color the cells:
  GREEN = palindrome (True)
  RED = not palindrome (False)
  GOLD border = computed more than once (overlapping!)

The grid for "aaba":
         0    1    2    3
    0   [T]  [T]  [F]  [F]
    1        [T]  [F]  [T]
    2             [T]  [F]
    3                  [T]

Mark cells (2,2) and (1,2) with gold borders: "These were checked multiple times!"

"Without cache: some pairs checked more than once."
"With cache: each (left, right) checked exactly once. O(n^2) pairs total."

Kit: "n^2 possible (left, right) pairs. Cache them all.
That IS the table you'll build in tabulation."

Gold box: "The overlap is small here but grows fast.
For a 10-character string: up to 55 unique pairs.
Without caching, calls multiply at each level."
