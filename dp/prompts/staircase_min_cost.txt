MIN COST CLIMBING STAIRS: Full Walkthrough
=============================================
The student already did the Climbing Stairs page.
Min Cost is the SECOND problem. Teach it fully from scratch:
question, DP triggers, choices, recursion, array, fill, code.

Example: cost = [10, 15, 20]
  Answer: $15 (start at step 1, pay $15, climb 2 to top)

Descriptive names:
  cost_to[step]        not  dp[i]
  cost[step]           not  cost[i]
  from_one_below       not  dp[i-1] + cost[i-1]
  from_two_below       not  dp[i-2] + cost[i-2]

Problem statement in a white card:
  "You are given an array cost where cost[i] is the price to step FROM step i.
   Once you pay the cost, you can climb 1 or 2 steps.
   You can start from step 0 or step 1 (both free to start on).
   Return the minimum total cost to reach the top."

Show the example visually below the staircase:
  cost = [10, 15, 20]

  Two paths shown with arrows on the staircase:

  PATH A (orange, more expensive):
    Start at step 0 (pay $10) -> climb 2 to step 2 (pay $20) -> top
    Total: $10 + $20 = $30

  PATH B (green, cheaper):
    Start at step 1 (pay $15) -> climb 2 to top
    Total: $15

  Label Path B as "CHEAPER!" with a green check.

Maya speech bubble:
  "Each step has a toll. I pay the toll, then climb 1 or 2 steps.
   What's the cheapest way to the top?"


SECTION 2 (badge: "2"), "SPOT THE DP TRIGGERS":
Header: "HOW DO I KNOW THIS IS DP?"

Show 3 items in a visual checklist, each with a GREEN check icon:

TRIGGER 1: "CHOICES AT EACH STEP" (green check)
  Show Maya on step 1 with two arrows:
    Green arrow up 1 step: "climb 1 (go to step 2)"
    Orange arrow up 2 steps: "climb 2 (jump to top)"
  "At each step: climb 1 or climb 2. Same choices as Climbing Stairs."

TRIGGER 2: "BEST ANSWER NEEDS BEST PREVIOUS ANSWERS" (green check)
  Show step 2 with two arrows pointing DOWN to step 1 and step 0:
    "Cheapest to step 2 = cheaper of:
     (cheapest to step 1) + toll at step 1, OR
     (cheapest to step 0) + toll at step 0"
  "I can't solve step 2 without FIRST solving step 1 and step 0."

TRIGGER 3: "SAME SUBPROBLEM ASKED MORE THAN ONCE" (green check)
  Show a diagram:
    Top (step 3) points back to: step 2 AND step 1
    Step 2 points back to: step 1 AND step 0

  Circle "cheapest to step 1" in YELLOW (#F5C542). Draw lines showing
  both step 2 and top need it.

  "See? 'Cheapest to step 1' is asked by step 2 AND by the top.
   Same question, asked twice. Overlapping subproblems."

Maya speech bubble:
  "All three triggers checked. It's DP."

Gold highlight box at the bottom:
  "WHEN YOU SEE A NEW PROBLEM, ASK:
   1. Do I have CHOICES at each step?
   2. Does the best answer need the best PREVIOUS answers?
   3. Is the same sub-question asked more than once?
   All three? It's DP."

Formula in a gold highlight box:

      cheapest_to(step - 1) + cost[step - 1],
      cheapest_to(step - 2) + cost[step - 2]
  )

Maya speech bubble:
  "Same as Climbing Stairs, but min() instead of +, and each step has a toll."


SECTION 2 (badge: "4"), "THE RECURSIVE CODE":
Header: "TURN THE CHOICES INTO CODE"

Base cases in a small white card:
  cheapest_to(0) = 0   "Start on step 0 for free."
  cheapest_to(1) = 0   "Start on step 1 for free."

Code in a dark navy code block:
  cost = [10, 15, 20]

  def cheapest_to(step):
      if step == 0: return 0
      if step == 1: return 0
      from_one_below = cheapest_to(step - 1) + cost[step - 1]
      from_two_below = cheapest_to(step - 2) + cost[step - 2]
      return min(from_one_below, from_two_below)

  cheapest_to(3)   # top = past the last step

Annotations:
  from_one_below -> green label: "came from one step back + its toll"
  from_two_below -> orange label: "came from two steps back + its toll"
  min(...)       -> "pick the cheaper path"


SECTION 3 (badge: "5"), "THE TREE":
Header: "DRAW THE CALLS"
Subtitle: "cheapest_to(3), expanded"

              3
            /   \
          2       1
        /   \
      1       0
    (base)  (base)

Left branches: "from 1 below" in green.
Right branches: "from 2 below" in orange.
Base nodes (0 and 1) have gold fill.

Circle both "1" nodes in yellow. Dashed line between them.
"cheapest_to(1) asked TWICE. Same answer both times."

SECTION 3 (badge: "8"), "THE CODE":
Header: "THE SOLUTION"

Code in a dark navy code block:
  def min_cost_stairs(cost):
      steps_to_top = len(cost)
      cost_to = [0] * (steps_to_top + 1)

      cost_to[0] = 0
      cost_to[1] = 0

      for step in range(2, steps_to_top + 1):
          from_one_below = cost_to[step - 1] + cost[step - 1]
          from_two_below = cost_to[step - 2] + cost[step - 2]
          cost_to[step] = min(from_one_below, from_two_below)

      return cost_to[steps_to_top]

Annotations:
  cost_to[0] = 0, cost_to[1] = 0  ->  "Free starting points (base cases)"
  for step in range(2, ...)        ->  "Left to right, after base cases"
  cost[step - 1]                   ->  "The toll at the step you came FROM"
  min(...)                         ->  "Pick the cheaper path"
  return cost_to[steps_to_top]     ->  "Last cell = cheapest total cost"

Gold highlight box at the bottom:
  "CLIMBING STAIRS vs MIN COST:
   Stairs:    ways[step] = ways[step-1] + ways[step-2]       (ADD all ways)
   Min Cost:  cost_to[step] = min(path_A, path_B)            (PICK cheapest)
   Same array. Same left-to-right fill. Different operation."
