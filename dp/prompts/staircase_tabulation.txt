STAIRCASE: YOUR FIRST DP TABLE (1D Tabulation)
================================================
Goal: Teach tabulation visually using the simplest DP problem.
One changing variable, one array, fill left to right.
The student already understands recursion and memoization.
The focus is entirely on: WHY is this an array? WHAT does each cell mean?
HOW do I fill it?

Character: Maya, a young rock climber with a chalk bag on her hip.
She writes numbers on the steps with chalk.
Golden chalk = base cases (already there before she starts).
White chalk = values she computes.

Problem: Climbing Stairs, n = 6 steps.
At each step: climb 1 or climb 2.
How many different ways to reach the top?

Descriptive names:
  count_ways(step)     not   climbStairs(n)
  ways[step]                not   dp[i]
  steps_to_top              not   n
  ways[step - 1]            not   dp[i-1]

Array for n=6: ways = [1, 1, 2, 3, 5, 8, 13]
Answer: ways[6] = 13

Images produced:
  Prompt 1 -> staircase_1.png  (Problem + Choices)
  Prompt 2 -> staircase_2.png  (Recursive tree + overlap)
  Prompt 3 -> staircase_3.png  (The 1D array: what it is, base cases, fill direction)
  Prompt 4 -> staircase_4.png  (Filling every cell, step by step)
  Prompt 5 -> staircase_5.png  (Bridge: 1D array vs 2D table)

PROMPT 2: Recursive Tree + Overlap -> staircase_2.png
================================================================================

Continue the tutorial. Tall portrait (1024x1792). SAME exact style and character.
ALL text HUGE. Phone-readable.

Stack 2 sections vertically:

SECTION 1, "THE TREE":
Header: "DRAW THE RECURSIVE TREE"
Subtitle: "count_ways(4), expanded."

Show a tree diagram. Each node is a circle with the number inside.
The tree shows count_ways(4):

                    4
                  /   \
                3       2
              /   \   /   \
            2      1  1    0
          /   \
        1      0

Label the branches: left branches say "climb 1", right branches say "climb 2".
Label the leaf nodes: "1" and "0" nodes have a gold glow and say "base case = 1 way"

NOW THE KEY VISUAL: Circle both "2" nodes (the one under 3, and the one under 4)
with a BRIGHT YELLOW GLOW. Draw a dashed line connecting them.

Big label between them:
  "SAME QUESTION! 'How many ways to reach step 2?'"
  "Appears TWICE. Same answer both times."

Maya looking at the tree, surprised:
  "Wait... I'm computing 'ways to reach step 2' TWICE. Same question, same answer.
   Why do the work twice?"

SECTION 2, "THAT'S WHY IT'S DP":
Header: "OVERLAPPING SUBPROBLEMS"

Show the tree again, but now with the duplicate "2" node CROSSED OUT (red X) and
replaced with a cache lookup.

Two panels side by side:
  LEFT (WITHOUT cache): Full tree, all nodes computed. "7 function calls."
  RIGHT (WITH cache): Smaller tree, duplicate "2" pulled from cache. "5 function calls."

The cache shown as a simple notepad/clipboard:
  step = 0 -> 1 way
  step = 1 -> 1 way
  step = 2 -> 2 ways  (solved once, looked up the second time)

Code in a box:
  def count_ways(step, memo={}):
      if step in memo: return memo[step]
      if step == 0: return 1
      if step == 1: return 1
      result = count_ways(step - 1, memo) + count_ways(step - 2, memo)
      memo[step] = result
      return result

Maya: "Same recursion. Just check the notepad before computing. That's memoization."

Bottom callout (gold border):
  "A problem is DP when:
   1. You make CHOICES (climb 1 or climb 2)
   2. The SAME subproblem appears MULTIPLE times
   3. Same question = same answer. Cache it."

Maya on step 4, looking back. She's getting faster, speed lines.

PANEL: STEP 5:
Array: [1, 1, 2, 3, 5, ? (highlighted), ?]
Arrow back to step 4 (value 5) and step 3 (value 3)

PANEL: STEP 6 (THE ANSWER):
Array: [1, 1, 2, 3, 5, 8, ? (highlighted with GOLD BORDER)]
Arrow back to step 5 (value 8) and step 4 (value 5)
Calculation: ways[6] = 8 + 5 = 13
Maya at the TOP of the staircase, arms raised in triumph!
The final cell glows GOLD.
BIG TEXT: "13 ways to climb 6 steps!"

Bottom: The tabulation code:
  def count_ways(steps_to_top):
      ways = [0] * (steps_to_top + 1)
      ways[0] = 1
      ways[1] = 1
      for step in range(2, steps_to_top + 1):
          ways[step] = ways[step - 1] + ways[step - 2]
      return ways[steps_to_top]

Annotate each line:
  ways[0] = 1, ways[1] = 1  ->  "Golden chalk (base cases)"
  for step in range(2, ...)  ->  "Left to right, after the base cases"
  ways[step-1] + ways[step-2] -> "Look back 1 + look back 2"
  return ways[steps_to_top]  ->  "Last cell = the answer"
