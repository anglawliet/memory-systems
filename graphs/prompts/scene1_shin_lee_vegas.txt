=============================================
5 prompts total: 1 character reference + 4 tutorial pages (1024x1792 each).
Story: Shin Lim, the world-famous card magician, explores Las Vegas venue by venue.
He picks one direction, goes ALL THE WAY through connected venues, dead end?
Comes back, tries the next venue. That IS depth-first search.

Sequence: start at The Strip → pick one venue, go ALL THE WAY → dead end
          (VIP only, sold out, closed)? → come back to the last fork →
          try the next venue → repeat until every venue has been visited.

Characters (Las Vegas magician themed):
  Shin Lim = the magician (explores deep first, comes back, tries the next spot)
  Chip = the casino chip (stack/path — drop a chip at each venue, follow chips back)
  Snap = the polaroid camera (visited — take a pic at each venue, already got the pic? Skip!)

The 7 Vegas Locations (graph):
  The Strip —— Bellagio —— Caesars Palace
      |             |
      |         Venetian —— The Sphere
      |             |
      +—— Fremont St —— High Roller

  Key: The Strip connects to BOTH Bellagio AND Fremont St (cycle!).
  This creates the "already visited" teaching moment.

DFS traversal order from The Strip:
  The Strip → Bellagio → Caesars Palace (dead end, come back)
  → Venetian → The Sphere (dead end, come back)
  → Fremont St → High Roller (dead end, come back)
  → Fremont St tries The Strip... SNAP ALREADY TAKEN! Already visited! Turn back!
  → Come back all the way to The Strip. Done!

Visual comparison — two panels side by side, each panel LARGE:

  Shin Lim enters Bellagio. Does NOT take a pic. Goes to Caesars Palace.

  Shin Lim enters Bellagio. Snap takes a pic IMMEDIATELY. Then explores.

Bold rule in gold box: "Snap BEFORE exploring = visited.add(venue) BEFORE the for loop. Always."

PAGE 7 — "DFS ON A GRID" (LARGE circled 7 top-right):
Header: "DFS ON A GRID" — "Same thing. Four directions instead of connected venues."

Show a 4x4 grid representing a Vegas floor plan from above. Some cells are WALLS (blocked, dark), others are ROOMS (open, neon). Classic "Number of Islands" setup.

The grid:
  R R W R
  R W W R
  W W R R
  R R R W
(R = room/open, W = wall/blocked)

Shin Lim explores from top-left. DFS goes: right, right... wall! Come back. Down... wall! Come back. Eventually explores all connected rooms.

KEY DIFFERENCE from venue map: 4 neighbors are DIRECTIONS (up, down, left, right), not a list.
Show the 4 directions as arrows: up, down, left, right.

Code (LARGE):
  def dfs(r, c):
      if r < 0 or r >= R or c < 0 or c >= C:
          return                    # off the map!
      if grid[r][c] == 'W':
          return                    # wall! Can't pass.
      if (r,c) in visited:
          return                    # already got the pic!
      visited.add((r,c))           # Snap takes pic FIRST
      dfs(r+1, c)                  # go down
      dfs(r-1, c)                  # go up
      dfs(r, c+1)                  # go right
      dfs(r, c-1)                  # go left

THREE reasons to turn back, shown as big icons:
  1. OFF THE MAP — Shin Lim at the edge of Vegas. Turn back!
  2. WALL — Shin Lim hits a wall. Can't pass. Turn back!
  3. POLAROID EXISTS — Shin Lim already has the pic. Already visited. Turn back!
Label: "Three reasons to turn back. Check ALL THREE before exploring."
