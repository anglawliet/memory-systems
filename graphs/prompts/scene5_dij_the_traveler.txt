"THE CODE (PYTHON)" (large section):
LARGE monospace code block, line-numbered, on a light gray/white background. Make the code BIG enough to read on a phone:
   1  def dijkstra(graph, start):
   2      dist = {node: float('inf')
   3              for node in graph}
   4      dist[start] = 0
   5      queue = []
   6      heapq.heappush(queue, (0, start))
   7      settled = set()
   8
   9      while queue:
  10          d, city = heapq.heappop(queue)
  11          if city in settled:
  12              continue
  13          settled.add(city)
  14          for nei, w in graph[city]:
  15              new_dist = d + w
  16              if new_dist < dist[nei]:
  17                  dist[nei] = new_dist
  18                  heapq.heappush(queue,
  19                      (new_dist, nei))
  20      return dist

  O((V + E) log V) with a heap
  V = number of cities (vertices)
