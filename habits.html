How I write any solution

These six habits stop mistakes early. Each habit comes from a real mistake. Use them in this order for every problem.

The six checks

Read the six habits before you practice. After a failed test, find the habit you skipped.

  1. Say what each variable means. Can I explain what each variable holds in one sentence?
  2. Write the jobs as comments first. Does every comment have a line of code?
  3. Name the type before the method. Is this a list, dict or set?
  4. Every loop must move forward. What changes inside this loop so it can stop?
  5. Check the small cases. What does my code return for an empty input?
  6. Trace a tiny example by hand. After each loop, do my variables have the values I expect?
Habit 1 of 6

Say what each variable means

We may swap left and right when we know their names but forget what they hold.

Before you code, describe each variable in one sentence. Say what it holds and when it changes.

For the longest substring, the variable left marks the window start. It moves only after a repeat. The variable right marks the window end. It moves in every loop.

Habit 2 of 6

Write the jobs as comments first

We miss lines when we remember the code shape but forget its jobs.

Write each job as a short comment. Then add code for each comment.

Habit 3 of 6

Name the type before the method

The code seen.pop(s[left]) crashed because a set's pop takes no value. The method was chosen before checking the type.

Before you add or remove something, name the type. It may be a list, dict, set, deque or heap. Then use the right method for that type.

Habit 4 of 6

Every loop must move forward

A while loop runs forever if its condition never changes. A window may also never shrink.

For every while loop, find the line that moves it closer to the end.

while s[right] in seen:  seen.remove(s[left])  # this makes the loop stop  left += 1
Habit 5 of 6

Check the small cases

Code may work on the main example but fail with no input, one item or all items the same.

Before you run the code, picture "", "a" and "bbbbb". Say what the code returns for each one.

Habit 6 of 6

Trace a tiny example by hand

An interview has no tests or hints. Tracing helps us find our own mistakes.

Choose an example with 4 items. After each loop, say the value of every variable.
