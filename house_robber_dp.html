The Problem

House Robber (LeetCode #198)

A row of houses, each with some money. Adjacent houses have connected alarms. If you collect from two houses next to each other, the alarm triggers. Find the maximum money without setting off alarms.

house 0house 1house 2house 3house 4

$7

$1
The constraint: Can't collect from two houses next to each other. So at each house, you're asking one question: do I take this house, or skip it?

Step 1: What Are My Choices?

At each house: take or skip

Standing at house 2 ($9). Two paths:

TAKE house 2
I grab the $9. But house 1 is off limits (adjacent!).
So I can only add $9 to whatever I got from house 0 and earlier.

money[house] + best_haul(house - 2)
SKIP house 2
I take nothing. House 1 is still available.
I keep whatever the best haul was through house 1.

best_haul(house - 1)

Pick whichever gives more money:

best_haul(house) = max(
    best_haul(house - 1),           # skip: keep previous best
    best_haul(house - 2) + money[house]  # take: grab cash, skip neighbor
)
How to find the choices (works for every DP problem):
1. Read the constraint (can't take adjacent)
2. At each step, ask: what can I do? (take or skip)
3. Write what happens in each case
4. The formula writes itself

Step 2: Choices → Recursion

The code writes itself from the choices

money = [2, 7, 9, 3, 1]

def best_haul(house):
    if house < 0: return 0            # no house, no money
    if house == 0: return money[0]    # one house? take it
    rob_this  = money[house] + best_haul(house - 2)
    skip_this = best_haul(house - 1)
    return max(rob_this, skip_this)

Step 4: Memoize

Same code, just cache the answers

def best_haul(house, memo={}):
    if house in memo: return memo[house]
    if house < 0: return 0
    if house == 0: return money[0]
    rob_this  = money[house] + best_haul(house - 2, memo)
    skip_this = best_haul(house - 1, memo)
    memo[house] = max(rob_this, skip_this)
    return memo[house]

The cache (notepad): house 0 → $2, house 1 → $7, house 2 → $11, house 3 → $11, house 4 → $12.

The Tabulation Code

Every line maps to something we just did

def max_robbery(money):
    house_count = len(money)
    if house_count == 0: return 0
    if house_count == 1: return money[0]

    best = [0] * house_count
    best[0] = money[0]
    best[1] = max(money[0], money[1])

    for house in range(2, house_count):
        skip_this = best[house - 1]
        rob_this  = best[house - 2] + money[house]
        best[house] = max(skip_this, rob_this)

    return best[house_count - 1]

Staircase vs House Robber

Same structure, different operation

Climbing Stairs
ways[step] = ways[step-1] + ways[step-2]
Operation: add (+)
Question: count ALL ways
Both look-backs: always used
House Robber
best[h] = max(best[h-1], best[h-2]+money[h])
Operation: max()
Question: find the MOST money
Look-backs: pick one (skip or take)
The pattern (same every time):
1. Read the constraint → find the choices
2. Choices → formula
3. Base cases → first cells
4. Fill left to right
5. Last cell = the answer
