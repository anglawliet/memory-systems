Step 1: How Do I Find the Choices?

A simple trick that works for every DP problem

Don't think about the whole problem. Follow these three steps:

A. Pick any step in the middle
Let's pick step 2. Don't worry about the whole staircase. Just focus on this one step.
B. Ask: "How could I have gotten here?"
Standing on step 2, look BACKWARDS. Only two ways I could have arrived:
Climbed 1 from step 1
I was on step 1, paid the $15 toll to leave it, and climbed 1 step up to step 2.
Climbed 2 from step 0
I was on step 0, paid the $10 toll to leave it, and climbed 2 steps up to step 2.

That's it. Those are the ONLY two ways. No other step can reach step 2.

C. The formula writes itself
For each way, write down the total cost. Then pick the cheaper one:
From step 1
cost_to[step - 1] + cost[step - 1]
"cheapest to get to step 1" + "toll to leave step 1"
From step 0
cost_to[step - 2] + cost[step - 2]
"cheapest to get to step 0" + "toll to leave step 0" 
cost_to[step] = min(
    cost_to[step - 1] + cost[step - 1],
    cost_to[step - 2] + cost[step - 2]
)
This recipe works for EVERY DP problem:
1. Pick any element in the middle
2. Ask "how could I have gotten here?"
3. List the ways (those are your choices)
4. Write the cost of each way
5. Combine: min for cheapest, max for most, + for count
6. That's your formula

Step 2: Choices → Recursion

The code writes itself from the choices

cost = [10, 15, 20]

def cheapest_to(step):
    if step == 0: return 0   # start on step 0 for free
    if step == 1: return 0   # start on step 1 for free
    from_one_below = cheapest_to(step - 1) + cost[step - 1]
    from_two_below = cheapest_to(step - 2) + cost[step - 2]
    return min(from_one_below, from_two_below)

Step 4: Memoize

Same code, just cache the answers

def cheapest_to(step, memo={}):
    if step in memo: return memo[step]
    if step == 0: return 0
    if step == 1: return 0
    from_one_below = cheapest_to(step - 1, memo) + cost[step - 1]
    from_two_below = cheapest_to(step - 2, memo) + cost[step - 2]
    memo[step] = min(from_one_below, from_two_below)
    return memo[step]

The cache: step 0 → $0, step 1 → $0, step 2 → $10, step 3 (top) → $15.

def min_cost_stairs(cost):
    steps_to_top = len(cost)
    cost_to = [0] * (steps_to_top + 1)

    cost_to[0] = 0
    cost_to[1] = 0

    for step in range(2, steps_to_top + 1):
        from_one_below = cost_to[step - 1] + cost[step - 1]
        from_two_below = cost_to[step - 2] + cost[step - 2]
        cost_to[step] = min(from_one_below, from_two_below)

    return cost_to[steps_to_top]

Climbing Stairs vs Min Cost

Same structure, different operation

Climbing Stairs
ways[step] = ways[step-1] + ways[step-2]
Operation: add (+)
Question: count ALL ways
Base cases: ways[0] = 1, ways[1] = 1
Min Cost Stairs
cost_to[step] = min(path_A, path_B)
Operation: min()
Question: find the CHEAPEST path
Base cases: cost_to[0] = 0, cost_to[1] = 0
Same array. Same left-to-right fill. Different operation.
Staircase: add all ways (+)
Min Cost: pick cheapest path (min)
House Robber: pick most money (max)
