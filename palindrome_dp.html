Palindrome DP

Is this substring a palindrome? Check the ends, then check the middle.

← Knapsack 2D Table → State Machine

The Problem

Palindromic Substrings (LeetCode #647)

Given a string, count how many substrings are palindromes. A palindrome reads the same forwards and backwards.

a a b a a

Palindromic substrings:

"a" x5 "aa" x2 "aba" "aabaa"
9 palindromic substrings

Step 1: What Are My Choices?

For any substring: is it a palindrome?

Pick any substring text[left..right]. To check if it's a palindrome, ask two questions:

1. Do the ends match?
text[left] == text[right]
If the outer characters don't match, it's NOT a palindrome. Done.
2. Is the middle a palindrome?
is_palindrome(left + 1, right - 1)
Peel off the ends. Check what's left. Recursive!

Example with "aabaa":

is_palindrome("aabaa", 0, 4)
  text[0]='a' == text[4]='a'?  YES
  Now check is_palindrome("aabaa", 1, 3)
    text[1]='a' == text[3]='a'?  YES
    Now check is_palindrome("aabaa", 2, 2)
      Single char 'b'. Always a palindrome. TRUE
    TRUE
  TRUE
Base cases:
left >= right (single char or empty) → always a palindrome. Return True.
text[left] != text[right] → not a palindrome. Return False.

Why each variable changes

CASE: text[left] == text[right] (Ends Match)
Action: Outer characters match. Peel them off and check the inner substring.
Immediate cost: None. A matching pair just means this layer is valid. The whole answer depends on what's inside.
State changes:
left → left+1: Confirmed text[left] matches the other end. Move inward from the left.
right → right-1: Confirmed text[right] matches the other end. Move inward from the right.
Remaining subproblem: Is text[left+1..right-1] a palindrome?
Call: is_palindrome(left+1, right-1)
Why both change? A palindrome is symmetric. We check both ends at the same time. Each confirmed match peels one character from each side. Advancing only one pointer would leave a confirmed character in the range, which is redundant.
CASE: text[left] != text[right] (Ends Don't Match)
Action: Outer characters differ. This substring is not a palindrome.
Result: Return False immediately. No recursion needed.
No state changes: We stop here. No deeper check required.
Why stop immediately? A palindrome must read the same forwards and backwards. If the outermost characters differ, no inner arrangement can fix that.

Step 2: Choices → Recursion

The code writes itself from the choices

def is_palindrome(text, left, right):
    if left >= right:
        return True
    if text[left] != text[right]:
        return False
    return is_palindrome(text, left + 1, right - 1)

def count_palindromes(text):
    count = 0
    for left in range(len(text)):
        for right in range(left, len(text)):
            if is_palindrome(text, left, right):
                count += 1
    return count
left >= right
Empty or single char. Always a palindrome.
text[left] != text[right]
Ends don't match. Not a palindrome.

Step 3: Spot the Overlap

Same (left, right) pair, multiple times

Checking all substrings of "aabaa":

is_palindrome(0,4) "aabaa"
  calls is_palindrome(1,3) "aba"  ─ ─ ─ ┐
    calls is_palindrome(2,2) "b"         │
                                         │ SAME!
Checking substring "aba" directly:       │
is_palindrome(1,3) "aba"  ─ ─ ─ ─ ─ ─ ─ ┘
  calls is_palindrome(2,2) "b"
is_palindrome(1, 3) computed TWICE
Once when checking "aabaa" (peels to "aba"), once when checking "aba" directly. Same state, same answer.

Cache key: (left, right). At most n² unique pairs.

Step 4: Memoize

Same recursion, just cache the results

def is_palindrome(text, left, right, cache):
    if left >= right:
        return True
    if (left, right) in cache:
        return cache[(left, right)]

    if text[left] != text[right]:
        result = False
    else:
        result = is_palindrome(text, left + 1, right - 1, cache)

    cache[(left, right)] = result
    return result

def count_palindromes(text):

Step 5: From Recursion to Table

What does each cell mean?

is_pal[left][right] = True if text[left..right] is a palindrome.

For "aab":

0 'a'1 'a'2 'b'
0 'a'TTF
1 'a'TF
2 'b'T

Only the upper triangle matters (left <= right). Count the T's: 4 palindromic substrings.

Fill by substring length

Start small, build up. Longer palindromes depend on shorter ones.

Length 1: every character
is_pal[0][0] = T, is_pal[1][1] = T, is_pal[2][2] = T
Single characters are always palindromes. Count = 3.
Length 2: check if both chars match
text[0]='a' == text[1]='a'? YES. is_pal[0][1] = T
text[1]='a' == text[2]='b'? NO. is_pal[1][2] = F
One matching pair. Count = 4.
Length 3: check ends + inner palindrome
text[0]='a' == text[2]='b'? NO. is_pal[0][2] = F
Ends don't match, no need to check inside. Count stays 4.

The Tabulation Code

Fill by increasing length

def count_palindromes(text):
    n = len(text)
    is_pal = [[False] * n for _ in range(n)]
    count = 0

    for i in range(n):
        is_pal[i][i] = True
        count += 1

    for i in range(n - 1):
        if text[i] == text[i + 1]:
            is_pal[i][i + 1] = True
            count += 1

    for length in range(3, n + 1):
        for left in range(n - length + 1):
            right = left + length - 1
            if text[left] == text[right] and is_pal[left + 1][right - 1]:
                is_pal[left][right] = True
                count += 1

    return count

Why fill by length?
is_pal[left][right] depends on is_pal[left+1][right-1] (a shorter substring). By filling shortest substrings first, the inner answer is always ready when we need it.

Recursion

def longest_palindrome(text):
    cache = {}
    best_start = 0
    best_length = 1

    for left in range(len(text)):
        for right in range(left, len(text)):
            if is_palindrome(text, left, right, cache):
                if right - left + 1 > best_length:
                    best_start = left
                    best_length = right - left + 1

    return text[best_start:best_start + best_length]

Uses the same is_palindrome with memoization from the parent.

Tabulation

def longest_palindrome(text):
    n = len(text)
    is_pal = [[False] * n for _ in range(n)]
    start = 0
    max_length = 1

    for i in range(n):
        is_pal[i][i] = True

    for i in range(n - 1):
        if text[i] == text[i + 1]:
            is_pal[i][i + 1] = True
            start = i
            max_length = 2

    for length in range(3, n + 1):
        for left in range(n - length + 1):
            right = left + length - 1
            if text[left] == text[right] and is_pal[left + 1][right - 1]:
                is_pal[left][right] = True
                if length > max_length:
                    start = left
                    max_length = length

    return text[start:start + max_length]
One line changed: instead of count += 1, track start and max_length. Same table, different bookkeeping.

The Pattern

2D table, fill by substring length

Palindromic Substrings
is_pal[l][r] = match AND is_pal[l+1][r-1]
Operation: count True cells
Fill order: by substring length (1, 2, 3, ...)
Longest Palindromic
is_pal[l][r] = match AND is_pal[l+1][r-1]
Operation: track max length
Fill order: same (by length)
Palindrome DP in one sentence: a substring is a palindrome if its ends match AND its inner part is already confirmed as a palindrome. Build from the inside out.
